## What This Folder Is

The `research/` domain holds intelligence sweeps, workspace briefings, and cross-domain synthesis reports. It is the archive's external-facing sensing layer: monitoring adjacent ecosystems, surfacing patterns, and translating broad landscape changes into actionable context for Atlas Lattice strategy.

This folder is valuable both for narrative orientation and for strategic situational awareness. It shows what the project was seeing in the world, how those observations were bundled, and which signals were considered relevant enough to preserve.
