# Tool Permission Gate

**Status:** public candidate  
**Canon:** no  
**Deployment:** no  
**Authority:** none  

Tools execute only through explicit permission and scoped intent.

## Tool hierarchy

ChatGPT may draft, review, summarize, classify, prepare packets, identify missing receipts, and recommend next actions.

Codex may patch under repo discipline.

Agents may propose.

Tools execute only through permission.

Humans ratify.

## No hidden escalation

No tool output should be interpreted as deployment, publication, canon, external authority, or institutional endorsement.

## Keeper line

Tools move work. Humans grant authority.
