# OpenAI-First Boundary

**Status:** public candidate  
**Canon:** no  
**Deployment:** no  
**Authority:** none  

OpenAI-first means this archive is structured to work well with ChatGPT, GPTBrain, Codex, file search, eval fixtures, review packets, and human-in-the-loop tool workflows.

It does not mean:

- official OpenAI endorsement
- OpenAI partnership
- OpenAI ownership
- OpenAI deployment
- OpenAI ratification
- OpenAI authority
- bypassing human-root review

## Allowed OpenAI-first claims

- optimized for ChatGPT-style reasoning
- structured for Codex patch planning
- prepared for eval fixtures
- designed for file-search and retrieval workflows
- human-gated and receipt-aware

## Forbidden OpenAI-first claims

- official OpenAI project
- OpenAI-approved
- OpenAI-deployed
- OpenAI-owned
- endorsed by OpenAI
- production OpenAI system

## Keeper line

OpenAI moves work. Governance grants authority.
