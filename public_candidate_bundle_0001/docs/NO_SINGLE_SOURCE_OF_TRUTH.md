# No Single Source of Truth

**Status:** public candidate  
**Canon:** no  
**Deployment:** no  
**Authority:** none  

Atlas Lattice does not use a single-source-of-truth model.

The system preserves many versions before synthesis. Alternate drafts, failed branches, fossil records, contradictions, model outputs, raw exports, summaries, and review packets can all coexist without being collapsed into one authority layer.

## Core invariant

```text
Many versions before synthesis.
Fossils preserved.
No hierarchy by default.
No canon by proximity.
No graph centrality as authority.
```

## Why this matters

A single-source-of-truth architecture can erase useful lineage. It can hide drift, overwrite failed-but-revealing branches, or allow a polished summary to impersonate raw evidence.

Atlas Lattice instead treats artifacts as reviewable coordinates inside a larger lattice. Different versions are preserved until synthesis is explicitly warranted.

## Geometry

The system may be represented through multiple compatible geometries:

```text
Metatron's Cube
12x12x12 hypercube lattice
Rainbow Yin Yang Lattice
Riemass S-curve on the yin-yang
```

These are not authority claims. They are coordinate and interface geometries for organizing review, retrieval, synthesis, and public-safe release.

## Fossil preservation

Failed branches, wrong turns, contradictions, and superseded drafts are not automatically deleted.

They may be:

```text
preserved
compressed
archived
quarantined
annotated
superseded
forked
reviewed
recovered
```

This preserves lineage without promoting every artifact to truth.

## Canon gate

Nothing is canon merely because it appears in GitHub, Drive, Notion, a model output, a graph cluster, or a polished synthesis.

An artifact becomes canonical only after:

```text
1. adversarial Pantheon Council review;
2. human-root adjudication by Dave Sheldon;
3. placement on the canonical website.
```

Until then, artifacts remain candidates, fossils, review packets, public-safe summaries, or non-canon scaffolds.

## Public-safe rule

```text
A public artifact can be useful without being canon.
A graph edge can show relation without promotion.
A cluster can show pattern without authority.
A fossil can preserve signal without deciding truth.
```

## Keeper

The lattice does not crown one version.
It preserves the field until synthesis is earned.
