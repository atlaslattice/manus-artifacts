## Core doctrine

Atlas Lattice / Rainbow Yin Yang Lattice does not use a single source of truth during the working phase.

It uses:

```text
many versions

many attempts

many candidate artifacts

```

Synthesis happens only after preservation, adversarial review, and human-root adjudication.

## Fossil preservation rule

```text
Failed branches are not trash.
Contradictions are not automatically errors.
Old drafts are not erased.
Weird outputs are not flattened.
Contaminated artifacts may still contain useful deltas.
```

The archive preserves fossils so later synthesis can see the full lineage of thought, drift, correction, failure, and emergence.

## No hierarchy principle

The system should not collapse into a hierarchy of one model, one document, one seat, one vendor, one repo, or one privileged source during exploration.

Working state is non-hierarchical and multi-version.

Review may route artifacts through lanes, but routing is not domination.

## Canon rule

Nothing is canon until:

```text

2. It survives adversarial Pantheon Council review.
3. Dave / human-root adjudicates.

```

Only the website-published result is canon.

Notion, Drive, GitHub, Gamma, GPTSwarm outputs, dream/play artifacts, and manuscripts are candidate, staging, mirror, receipt, fossil, or review surfaces until promoted.
