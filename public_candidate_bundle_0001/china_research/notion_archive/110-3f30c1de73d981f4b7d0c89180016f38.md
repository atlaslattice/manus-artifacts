## Purpose
This register preserves the distinction between **site-specific deployment truth** and **market / literature priors**.
It is intended to make the Dongjiakou simulation runnable and portable without weakening evidence discipline. A local value may remain `UNKNOWN` while the model carries one or more externally observed comparator ranges for scenario analysis.
## Required fields
For every unresolved site-specific input, record the **local value and comparator as an adjacent pair**:
- **Target variable**
- **Dongjiakou value / range**
- **Dongjiakou evidence status:** MEASURED / REPORTED / DERIVED / MODELED / UNKNOWN
- **Comparable project / external reference value or range**
- **Comparator source evidence:** MEASURED / REPORTED / MODELED
- **Comparator type:** same-site historical / same-region / same-technology / same-scale / cross-region / engineering model
- **Transferability:** HIGH / MEDIUM / LOW
- **Transfer risks:** climate, scale, feed chemistry, energy price, labor, regulation, financing, maturity, integration boundary
- **Scenario use:** lower bound / central reference / upper bound / sanity check only
- **Creditable at Dongjiakou:** NO unless promoted by a Dongjiakou receipt

## Simulation rule
The simulation may carry two parallel values:
`site_value = UNKNOWN`
`reference_distribution = externally sourced range`
A model run using the reference distribution must be labeled **TRANSFERRED_REFERENCE_SCENARIO**.
It may answer:
- What order of magnitude is plausible?
- Which unknowns dominate sensitivity?
- Under what externally observed conditions does the node become net-positive?
- Which technologies are obviously noncompetitive even under favorable reference assumptions?
It may **not** answer:
- What Dongjiakou actually costs today.
- What revenue Dongjiakou will actually earn.
- What local yield, availability or permit outcome is established.
- Whether deployment is approved or imminent.
## Why this matters for portability
A complete locality simulation should be able to start in a new geography before every local receipt is available.
The sequence is:
1. Load physical topology and local facts.
2. Mark unresolved local fields UNKNOWN.
3. Attach external comparator distributions with explicit transferability.
4. Run sensitivity / Monte Carlo only on sourced comparator ranges.
5. Rank the missing local receipts by decision sensitivity.
6. Replace comparator priors with local observations as they arrive.
7. Never let the prior inherit the evidence status of the local measurement.
This turns the Dongjiakou work into a reusable **locality estimation grammar**, not a one-off forecast.
## Promotion rule
An external comparator can improve the simulation's **resolution**, but never the node's **evidence class**.
> **REFERENCE narrows ignorance. It does not create a receipt.**
