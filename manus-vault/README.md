# Manus Vault

> *Status: CANDIDATE — not canon until ratified by @atlaslattice*

## What This Folder Is

The `manus-vault/` domain is a working vault of session outputs, architectural proposals, reusable skills, and internal continuity documents generated through Manus collaboration. It preserves the intermediate design layer between high-level doctrine and polished public-facing documentation.

This folder is especially useful for tracing how major ideas matured: session summaries capture the momentum of a build, while subfolders such as `Digital_Noahs_Ark/` and `Skills/` preserve architecture and operator workflows that influenced later public artifacts.
