## Purpose

This document explains the Atlas Lattice 12x12x12 hypercube as a candidate coordinate system for organizing knowledge, artifacts, claims, evidence, reviews, and public-safe releases.

It is not a completed scientific standard. It is not canon. It is not a deployment claim. It is a public-candidate ontology explainer for review.

## One-line summary

The lattice is a candidate map for making knowledge inspectable: every artifact should have coordinates, provenance, claims, receipts, review state, and promotion boundaries.

## What the 12x12x12 means

The 12x12x12 structure is a candidate hypercube model:

- 12 top-level houses or domains
- 12 subdomains per house
- 12 working lanes, states, modules, or review dimensions per subdomain

This gives a symbolic maximum of 1,728 coordinate cells. The number is useful because it is large enough to hold complexity, but structured enough to make gaps, contradictions, missing receipts, and review states visible.

## What the lattice is

The lattice is a knowledge-graph coordinate system.

It can map source artifacts, raw exports, parsed packets, claims, evidence anchors, missing receipts, hash gaps, review findings, contradictions, supersessions, quarantine decisions, public-candidate bundles, and human-root promotion decisions.

## What the lattice is not

The lattice is not canon, truth by itself, a scientific standard by assertion, an authority engine, a replacement for human review, proof that a repository is complete, proof that a source was fully exported, proof that a model output is safe for publication, or proof of OpenAI endorsement or integration.

## Periodic Table 2.0 ambition, not completed standard

A useful analogy is a candidate “Periodic Table 2.0” for knowledge organization.

That phrase names the ambition: a compact structure that helps people locate patterns across domains. It does not claim that the lattice has the maturity, consensus, predictive power, or empirical grounding of the chemical periodic table.

Safe claim:

```text
The lattice is a candidate coordinate system that aims to make source-grounded knowledge easier to inspect, compare, and review.
```

OpenAI-first means the workflow can be optimized for reasoning, retrieval, evaluation, structured outputs, graph construction, and review workflows using OpenAI tools where appropriate.

It does not mean OpenAI has endorsed, integrated, certified, or verified the project or the ontology.

Safe wording:


## GitHub is the public shelf, not canon

GitHub is useful as a durable public receipt shelf for safe files, code, schemas, issues, review notes, CI checks, and reproducible artifacts.

But GitHub is not canon by default.

A GitHub file can be source material, receipt, staging artifact, candidate explainer, review packet, public-safe demo, or test fixture. It becomes canon only after an explicit human-root promotion event.

## Receipts are not truth

A receipt proves that something exists, was logged, or was mirrored. It does not prove that the claim inside the receipt is true.

The graph should separate:

```text
source -> parsed artifact -> claim -> evidence anchor -> review finding -> decision -> action
```

This prevents truth laundering, where a clean-looking index accidentally makes unsupported claims look verified.

## Missing receipts are graph nodes

A missing receipt should not disappear into prose.

It should become a graph node:

```text
MissingReceipt -> blocks -> Claim / Artifact / Export / Review / Release
```

Likewise, missing hash becomes a HashGap node, partial export becomes ExportGap status, not found becomes a search result state, and blocked dependency becomes a blocked_by edge.

## Human-root promotion boundary

Human-root review is required before any candidate becomes canon or public-release authorized.

The promotion path should look like:

```text
raw source
  -> parsed artifact
  -> public-candidate packet
  -> review findings
  -> release gate
  -> human-root decision event
  -> promotion state update
```

No model consensus, graph centrality, GitHub receipt, or beautiful synthesis can skip this boundary.
