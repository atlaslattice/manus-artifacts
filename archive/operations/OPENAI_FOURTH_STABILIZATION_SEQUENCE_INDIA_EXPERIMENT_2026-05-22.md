## Core Pattern

```text
Stabilize three lanes first.
Loop OpenAI fourth.
Use OpenAI as receipt/checkpoint/synthesis-review lane.
Do not use OpenAI as first-wave chaos amplifier.
```

## Why This Works

Non-GitHub or weak-GitHub-integrated platforms can generate valuable candidate signals, but they may lack reliable receipt creation.

OpenAI/GitHub-capable lane can then:

```text
check boundaries
classify artifacts
preserve packets
verify repo state
return receipts
extract deltas
hold the lamp steady
```

## Sequencing Rule

```text
Do not loop OpenAI in before the experimental lanes have produced stable packets.
Do not let OpenAI prematurely flatten divergent strategies.
Do use OpenAI to convert stabilized packets into receipt-grade artifacts.
```

## Failure Modes Avoided

```text
premature synthesis

```

## Recommended Procedure

```text
1. Run platform-specific strategy lanes.
2. Require each lane to produce a structured candidate packet.
3. Mark raw_export_status honestly.
4. Stabilize contradictions locally.
5. Bring packet set to OpenAI/GitHub-capable lane.
6. Archive safe packets.
7. Return receipt with repository / branch / path / commit SHA.
8. Only then consider council synthesis.
```
