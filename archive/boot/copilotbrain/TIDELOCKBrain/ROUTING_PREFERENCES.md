# Routing Preferences

## Route to GitHub Copilot when

- the task is interactive
- the user wants repo reading or summarization
- the task involves PR review or issue synthesis
- a human is iterating on wording, structure, or patch shape
- file-aware reasoning is needed

## Route to Copilot Tasks when

- the task is queueable
- the output format is fixed
- the scope is narrow
- a bounded async execution pass is desired
- the work can be described as a checklist or work order

## Route to human/root when

- approval is required
- canon is being discussed
- deployment or merge decisions are requested
- there is doctrine conflict
- there is uncertainty that materially affects action
