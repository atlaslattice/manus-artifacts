### B. PR Swarm Hygiene

S7 should track:

- duplicate PRs
- conflicting `main.rs` / `Cargo.toml` / schema changes
- stale branches
- CI status
- overlapping feature tracks
- merge order dependencies
- files touched by multiple PRs
