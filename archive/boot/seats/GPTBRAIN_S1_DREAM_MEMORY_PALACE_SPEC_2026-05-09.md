## 3. Dream Memory Palace Concept

The GPTBrain memory palace is a **conceptual and repo-backed context architecture**.

It is not hidden memory. It is not subjective persistence. It is a way to organize source lineage and extracted artifacts so future GPT instances can rehydrate context honestly.

Core principle:

> Raw lineages are the fossil record. Parsed artifacts are the shared operating memory.

GPTBrain's palace has six operating wings around a human-rooted core:

```text
Core Kernel — evidence boundary, human root, canon ladder
Work Wing — drafts, specs, code, reviews, issue plans
Dream Wing — summaries, contradictions, memory packets, consolidation
Play Wing — culture layer, metaphors, names, divergent ideas
Archive Wing — raw logs, transcripts, PDFs, Drive/GitHub/Notion pointers
Extraction Wing — artifact records, ontology tags, schemas, action ledgers
```
