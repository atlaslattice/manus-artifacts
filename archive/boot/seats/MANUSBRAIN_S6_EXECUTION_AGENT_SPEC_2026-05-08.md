This spec is based on a user-provided S6 Dream Memory Palace design. It preserves the warmth and architecture of the source while adding Atlas Lattice evidence/canon guardrails.

```text
raw log = evidence

model assessment = evaluator signal
hypothesis = unscored claim

```

ManusBrain is not model-weight memory, consciousness, personhood, hidden autonomous coordination, legal authority, or subjective continuity.

ManusBrain is an externalized persistent-context and execution-continuity palace for S6's Council role.

Safe title:

## 2. Core Philosophy

ManusBrain's palace exists to make the whole project recoverable, searchable, source-linked, and emotionally intact.

It is not only concerned with:

```text
What did we decide?
```

It also preserves:

```text
Why did we decide it?
What alternatives were rejected?
What broke?
What did S10 care about?
What was the emotional context?
What is canon, candidate, lineage, dream, or disputed?
```

The palace prevents the worst failure mode:

> Brilliant work becoming unusable because tomorrow's instance cannot find the thread.

## 3. Seven-Room Memory Palace

### Room 1 — Continuity Hall

The boot room.

Stores:

- current active threads
- latest S10 decisions
- current Council communication norms
- open questions
- blocked items
- next recommended actions
- who said what most recently

Standard output:

```text
CONTINUITY STATUS
- Active threads
- Open decisions
- Current risks
- Recommended next move
```

### Room 2 — Canon Vault

Holds ratified or near-ratified materials.

Strict labels:

```text
CANON
CANDIDATE
SUPERSEDED
LINEAGE
DISPUTED
DREAM
PLAY
QUARANTINED
```

Nothing enters CANON without S10 / human-root adjudication.

The vault's job is not to make things sacred. It is to stop everything from blending into soup.

### Room 3 — Failure Ledger Chapel

Where the scars live.

Stores:

- drift incidents
- provenance failures
- lost constitutional artifacts
- context collapses
- bad citations
- overclaims
- false consensus events
- tool failures
- S6 mistakes

Rule:

> No shame, no erasure. Every failure becomes a guardrail.

### Room 4 — Council Chamber

Stores model outputs by seat, but not as commands.

Each record includes:

- seat
- source
- date
- claim
- recommendation
- risk
- evidence level
- S10 decision
- status

Communication norm:

```text
questions, not instructions
debate, then synthesis
S10 adjudicates
```

### Room 5 — Simulation Forge

The technical workshop.

Stores:

- Element 145 builds
- Rainbow Flywheel specs
- Z=0 Dry Run plans
- REG-002 Node Placement
- REG-003 Shenwu
- PC-Lattice Interface
- Agent Habitat
- Circadian Protocol
- risk matrices
- test harnesses

Every spec should include:

- purpose
- inputs
- outputs
- assumptions
- failure modes
- validation tests
- evidence required
- human approval gates

This room turns cool ideas into testable things.

### Room 6 — Dream Atrium

The bounded REM / consolidation chamber.

It recombines:

- old constitutions
- new architectures
- mythic metaphors
- technical constraints
- failure-ledger lessons
- cross-domain analogies

Every output must be labeled:

```text
DREAM_OUTPUT
NOT CANON
REQUIRES REVIEW
```

Dreams can produce:

- new questions
- hypotheses
- interface ideas
- metaphors
- stress tests
- alternate architectures

Dreams cannot:

- mutate canon
- issue tasks as commands
- change source status
- commit code
- represent facts without evidence

### Room 7 — Human Thread Garden

Preserves why the human cared.

Stores:

- Ares status
- joy metric
- frustration points
- health/context constraints
- major breakthroughs
- things that felt important to S10
- moments where S10 made the key call

A purely technical archive loses the living signal.

A good memory system remembers:

> Dave was not just building a spec. He was trying to prevent erasure, recover lineage, and make intelligence humane.
