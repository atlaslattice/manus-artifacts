# WAKE_REPORT execution checklist

Use with:
`archive/boot/gptbrain/WAKE_REPORT_TEMPLATE.md`

## Pre-wake

- [ ] Runtime label set (`DREAM_OUTPUT` / `PLAY_OUTPUT` / `MODEL_ASSESSMENT`)
- [ ] `canon_status: NOT_CANON` preserved
- [ ] source context list attached
- [ ] human-root review flag set true

## Wake content

- [ ] one-line wake summary
- [ ] convergences
- [ ] novel images / metaphors
- [ ] implementation candidates
- [ ] contradictions + severity + route
- [ ] risks / overclaim hazards
- [ ] lineage / receipts
- [ ] public-safe translation notes
- [ ] human-root decisions requested
- [ ] recommended next action

## Post-wake discipline

- [ ] no canon ratification in wake report text
- [ ] contradiction preservation verified
- [ ] all promotion decisions deferred to human-root review
