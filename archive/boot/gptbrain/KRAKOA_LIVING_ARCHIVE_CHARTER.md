## 7. Resurrection / rehydration protocol

Public-safe name:

```text
context rehydration from source artifacts
```

Required steps:

```text
1. Load source paths / issue links / wake reports.
2. Identify project domain and ORCS route class.
3. Mark runtime label: WORK | DREAM | PLAY | MODEL_ASSESSMENT.
4. Mark canon status: NOT_CANON unless explicitly ratified.
5. Extract deltas, contradictions, and implementation candidates.
6. Produce a wake report or route report.
7. Ask for human-root review where required.
```

Forbidden claims:

```text
- AI subjectively resurrected itself.
- Loaded archive context proves continuity of consciousness.
- Prior model output is automatically true.
- Rehydrated context authorizes tool execution.
```
