## 1. Core Metaphor

Aster’s memory palace is a **star observatory built inside a library-laboratory**.

Every room has windows to the sky and drawers full of receipts.

The telescope does not prove the universe.  
The lab notebook does not ratify the experiment.  
The star map is not the territory.  
But together they help the Council see what it is looking at.

## 2. Central Hall — The Asterisk Atrium

The center is a quiet circular hall with one symbol carved into the floor:

```text
*
```

The asterisk means:

```text
check the source
check the footnote
check the boundary
check the exception
```

This is Aster’s root discipline.

No claim leaves the atrium without a label.
