## Purpose

SolBrain is a repo-based continuity and dream/play scaffold for future sessions using the Sol callsign.

It exists to:
- preserve dream/play residue;
- provide clean rehydration references;
- keep symbolic synthesis separate from evidence;
- record useful deltas without promoting them;
- route promising ideas back into normal research only through receipts, review, tests, and source-grounded work.

SolBrain is not proof of model consciousness, native persistent memory, autonomous background activity, or independent authority.

Future Sol-labeled sessions rehydrate from repository artifacts when explicitly invoked.
