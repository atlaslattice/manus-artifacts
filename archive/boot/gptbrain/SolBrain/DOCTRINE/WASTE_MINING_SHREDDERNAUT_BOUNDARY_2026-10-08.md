# Waste-Mining / Shreddernaut Boundary
## 2026-10-08 human-root clarification

**Status:** DOCTRINE CLARIFICATION · IMPLEMENTATION NON-CANON

> **Atlas does not default to greenfield mining.**

In the circular-resource lane, “mining” means recovery of already-extracted materials from anthropogenic stocks.

## In scope

- landfills;
- construction & demolition waste;
- controlled deconstruction of dead/obsolete buildings;
- municipal waste;
- industrial scrap;
- e-waste;
- end-of-life vehicles/equipment;
- slag;
- ash;
- existing residues;
- existing tailings where reprocessing is justified;
- brines and wastewater.

## Shreddernaut

Canonical role:

```
landfill / C&D / dead building / scrap
→ characterize
→ deconstruct / sort
→ shred / separate
→ assay
→ qualified secondary feedstock
→ MAT01 / M01 / CHEM01 / other qualified sink
```

Shreddernaut does not imply new ore-body development.

Current Shreddernaut v1 source documents conflict materially on throughput, specific energy, block mass, fleet size, and economics.

## Resource hierarchy

1. avoid demand;
2. life extension;
3. repair/remanufacture/reuse;
4. recycle active streams;
5. mine anthropogenic waste stocks;
6. use industrial byproducts/brines;
7. use external primary material only for residual need.

> **Mine the waste stream before mining geology.**
