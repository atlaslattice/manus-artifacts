### 1. Identity / state / environment

```text
identity + state + environment -> behavior
```

This is a research framing, not a new physical law.

### 2. Shared experimental grammar without shared mechanism

Different domains resisted collapse into a universal explanation.

What survived:

```text
alter the pathway
observe the response
preserve the receipt
```

Examples:
- charge state changes available decay channels;
- sonoelectrochemistry can alter transport/interface conditions;
- low-frequency acoustic forcing can alter flame/flow behavior;
- substrate vibration can alter biological signaling/sensing.

These mechanisms remain physically distinct.

### 4. Transformation records may be as important as object records

Persistent play motif:

```text
Do not only ask what an object is.
Ask what changed as it moved between states.
```

Example abstraction:

```text
isotope in feed
-> interface state
-> transported/intermediate state
-> product state
```

Research question:

```text
What remained invariant?
What changed?
Which variable was actually measured?
```

### 5. Failure should improve the archive

Useful residue:

```text
A failed mapping can add a boundary to the knowledge graph.
A null result can make the system more useful.
```

Examples:
- beautiful Rainbow mapping fails control -> preserve failure;
- acoustic effect disappears under hydrodynamic control -> preserve explanation;
- Atlas loses to conventional baseline -> ontology may remain useful without discovery claim;
- shuffled HSN matches predictive performance -> downgrade multidomain hypothesis.
