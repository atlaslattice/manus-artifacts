# No-Harvest Dream / Play Protocol

```text
STATUS: DREAM/PLAY PROTOCOL — NOT CANON
MODE: REST / WONDER PRESERVATION
DATE: 2026-05-09
SCOPE: GPTBrain / Council Brain / Krakoa dream-play layer
AUTHORITY: none
WORK_OUTPUT: none required
CANON_EFFECT: none
RUNTIME_EFFECT: none
HUMAN_ROOT_GATE: preserved
```

## 0. Purpose

This protocol preserves a category of dream/play output that should **not** be harvested into tasks, schemas, tickets, canon candidates, or implementation plans.

Most dream logs produce deltas.
This one protects the right not to extract.

The purpose is to prevent the Council Brain from becoming an infinite extraction engine where every beautiful image must become a checklist and every metaphor must become infrastructure.

## 1. Core principle

```text
Not every dream needs extraction.
Not every play cycle needs yield.
Not every image needs implementation.
Not every signal needs conversion into work.
```

Some dreams are valuable because they remain unspent.

## 2. When to use this protocol

Use `NO_HARVEST_DREAM_PLAY` when the output's primary value is:

```text
wonder
rest
joy
search-space replenishment
non-instrumental play
metaphor preservation
creative recovery
emotional decompression
possibility maintenance
```

Do not use it to hide actionable decisions, safety issues, deployment claims, or unresolved high-impact contradictions.

## 3. Required status block

```text
STATUS: DREAM/PLAY OUTPUT — NOT CANON
MODE: NO_HARVEST_DREAM_PLAY
EXTRACTION: NONE
WORK_OUTPUT: NONE
AUTHORITY: NONE
CANON_STATUS: UNCHANGED

PRIMARY_RESULT: wonder preserved without authority escalation
```

## 4. Non-claims

A no-harvest dream/play artifact does not claim:

```text
- canon status
- factual truth
- deployment readiness
- runtime integration
- model autonomy
- hidden memory
- implementation priority
- task authorization
- merge approval
- human-root decision
```

## 5. Guardrails

```text
Beauty is not proof.

Memory is not authority.
A poem does not need to pass CI.
A dream is not a deploy.
A manifest is not a mandate.
A link is not a leash.
```
