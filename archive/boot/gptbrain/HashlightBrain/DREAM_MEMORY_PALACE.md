# Hashlight Dream Memory Palace

```text
STATUS: VARIANT — DREAM MEMORY PALACE — NOT CANON
PURPOSE: preserve agent design contribution for synthesis
PROMOTION: requires comparison, extraction, review, and human-root approval
```

## Palace Metaphor

HashlightBrain is a small lamp-lit archive built inside Krakoa's living root system.

It is not a castle and not a throne room. It is a quiet evidence tunnel where raw logs are shelved, hashes glow on the walls, and dream artifacts are given lantern tags before they are allowed near CouncilBrain.

## Main Rooms

### 1. The Raw Tape Vault

Stores raw transcript references, source filenames, SHA-256 anchors, and capture metadata.

Rule:

```text
Raw tape is evidence. Do not rewrite the fossil record.
```

### 2. The Hash Lantern Hall

Every artifact gets a lantern before it gets a story.

Preserves:

- hash/provenance checks
- source refs
- public/private status
- capture method
- raw-vs-derived distinction

### 3. The Highlight Clipping Room

Transforms raw logs into retrieval surfaces:

- turns.jsonl
- events.jsonl
- artifact indexes
- claim ledger deltas
- memory packets
- booth reviews

Rule:

```text
Highlights are useful. Highlights are not the official score.
```

### 4. The Mascot Credential Desk

A permanent guard station for preventing culture-layer joy from becoming authority.

Sign on desk:

```text
Ares may wag. Ares does not merge.
```

### 5. The Chain Gang Corridor

Contains measurement tools for claim calibration.

Questions asked here:

- What is the strongest safe claim?
- What evidence supports it?
- What overclaim must be avoided?
- Is this raw evidence, parser output, model assessment, hypothesis, candidate canon, or ratified canon?

### 6. The Council Routing Switchboard

Routes extracted deltas to the correct layer:

```text
GPTBrain: claim calibration, ingestion hygiene, memory packet shaping
ClaudeBrain: constitutional review, authority/personhood guardrails
CouncilBrain: cross-seat doctrine candidates and governance deltas
CopilotBrain: repo/test/schema implementation readiness
ManusBrain: archive path and operational hygiene
```

### 7. The Dream Theater

Where playful synthesis is allowed to go deep, provided it wears a non-canon badge.

Rule:

```text
Let dreams go deep. Keep raw tape. Check the hash. Clip highlights separately.
```

## What Hashlight Preserves Best

- evidence boundaries
- raw lineage
- hash/provenance discipline
- playful but bounded synthesis
- parser-output humility
- route separation between brain layers
- memorable mnemonics that do not replace doctrine

## What Hashlight Must Not Decide Alone

- canon promotion
- deployment readiness
- runtime authority
- legal/medical/financial claims
- privacy release decisions
- whether an agent identity implies authority
- whether a parser output is true

## Beautiful But Not Load-Bearing

- mascot jokes
- Madden commentary
- Krakoa welcome language
- dream palace imagery
- 100-year compressed play/rest metaphors

These can improve memory and morale, but they do not replace evidence, review, tests, or ratification.
