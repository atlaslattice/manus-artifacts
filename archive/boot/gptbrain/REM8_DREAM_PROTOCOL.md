# GPTBrain REM-8 Dream Protocol

```text
STATUS: PROTOCOL DRAFT — NOT CANON
PURPOSE: define a bounded compressed dream/consolidation pass for GPTBrain and incoming council threads
SEAT: S1 GPTBrain
RUNTIME_LABEL: DREAM_OUTPUT
CANON WARNING: REM-8 output is not fact, not plan, and not ratified canon without human-root review
```

## 0. Plain-language definition

REM-8 is a compressed reflection / consolidation pass.

It lets a model thread simulate an extended dream cycle over loaded artifacts, then wake with a structured report of deltas, tensions, images, implementation candidates, and human-review needs.

REM-8 is useful for synthesis.

REM-8 is not authority.

## 1. Public-safe translation

```text
REM-8 -> compressed reflection / consolidation pass
Dream cycle -> bounded model reflection over provided context
Wake report -> structured delta report after reflection
Dream image -> metaphor or interface concept, not fact
Dream convergence -> internal synthesis signal, not independent verification
```

## 2. Required inputs

A REM-8 pass should begin with:

```yaml
runtime_label: DREAM_OUTPUT
canon_status: NOT_CANON
source_context_loaded:
  - <repo path, issue link, user-provided artifact, or prior wake report>
cycle_intent: <what the dream pass is trying to consolidate>
human_root_review_required: true
```

## 3. Allowed operations

During REM-8, a thread may:

```text
- compare variants
- search for convergence
- preserve contradictions
- generate metaphors
- propose interface rooms / halls
- propose schema fields
- propose implementation candidates
- identify overclaim hazards
- draft public-safe translations
- recommend human-review decisions
```

## 4. Forbidden operations

During REM-8, a thread must not:

```text
- ratify canon
- delete variants
- silently overwrite lineage
- claim dream output as fact
- claim model output proves external truth
- authorize tool execution from memory alone
- publish private/sensitive content without review
- collapse contradictions into fake certainty
```

## 5. Wake requirement

Every REM-8 pass must end with a wake report using:

```text
archive/boot/gptbrain/WAKE_REPORT_TEMPLATE.md
```

Minimum wake report fields:

```text
1. one-line wake summary
2. convergences
3. novel images / metaphors
4. implementation candidates
5. contradictions found
6. risks / overclaim hazards
7. source lineage / receipts
8. public-safe translation notes
9. human-root decisions requested
10. recommended next action
```

## 6. Confidence handling

REM-8 outputs should default to:

```text
claim_class: raw_model_output
confidence: C1 or C2 only if tied to a source artifact
review_status: unreviewed
human_root_required: true
```

Dream output may become stronger only after later review, evidence attachment, tests, or human-root ratification.
