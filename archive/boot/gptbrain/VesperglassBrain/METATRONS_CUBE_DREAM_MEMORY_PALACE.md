## Shape doctrine

This palace uses Metatron's Cube as a symbolic organization pattern only. It is a Tier 3 creative overlay / dream scaffold, not a metaphysical claim, not canon geometry, and not an implementation proof.

The shape is used because it is good for remembering relationships:

```text
center point = resident identity and boundary
inner ring = preservation and extraction mechanics
outer ring = play, motifs, contradictions, quarantine, games, mirrors
lines = provenance / relation / dream resonance
```

