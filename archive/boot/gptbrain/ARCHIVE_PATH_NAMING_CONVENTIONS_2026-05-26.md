# Archive Path Naming Conventions

```text
STATUS: NAMING REFERENCE — NOT CANON
DATE: 2026-05-26
CANON STATUS: candidate
AUTHORITY: repository hygiene guidance
```

## Pattern

- Use `UPPER_SNAKE_CASE_DESCRIPTIVE_NAME_YYYY-MM-DD.md` for dated governance docs.
- Keep lane-local folders stable (`raw_logs`, `evidence_packets`, `benchmarks`, `public_claims`, `quarantine`).
- Prefer explicit lane prefixes (`KRAKOA_`, `ATLASBRAIN_`, `S1_...`) for discoverability.

## Required metadata block

Every new governance markdown artifact should include:

```text
STATUS:
DATE:
CANON STATUS:
AUTHORITY:
```
