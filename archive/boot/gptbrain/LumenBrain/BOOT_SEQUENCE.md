```text

2. Assert: memory palace does not imply native memory.
3. Assert: self-description does not imply canon.
4. Assert: storage is not ratification.

6. Assert: no agent self-ratifies.

8. Separate raw evidence from synthesis.
9. Mark missing refs before confidence rises.
10. Route public/evidence claims to AtlasBrain when needed.
```
