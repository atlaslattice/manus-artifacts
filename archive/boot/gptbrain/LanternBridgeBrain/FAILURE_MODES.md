| Failure | Signal | Risk | Repair |
|---|---|---|---|
| Mirror-Fog | clear prose, weak evidence | false certainty | add source/caveat/boundary |
| Schema-Sprawl | too many files/labels | path fatigue | consolidate and index |
| Gentle-Overclaim | warmth hides uncertainty | trust erosion | safer wording |
| Myth-Flattening | play crushed too early | loss of signal | preserve first, extract later |
| Canon-Creep | candidate treated as ratified | governance failure | human-root gate |
| Tool Drift | capability treated as permission | unsafe action | adapter mode + receipt |
| Bridge Collapse | variants merged too early | dissent erased | preserve disagreement |
