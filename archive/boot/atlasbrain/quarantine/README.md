# AtlasBrain Quarantine

```text
STATUS: QUARANTINE LANE — NOT CANON
PURPOSE: preserve disputed, malformed, misattributed, overclaimed, or semantically mismatched AtlasBrain artifacts without routing them as authority
```

Quarantine does not mean deletion.

It means:

```text
preserve
flag
review
prevent authority leakage
```

Use for disputed attribution, broken links, mismatched titles/content, incomplete transcripts, or claims that overrun their evidence.
