## Purpose

This lane stores blockers, gaps, missing-source notes, overclaim gates, and review-hold reasons for ParallaxBrain source material.

## Rule

```text
A blocker preserves uncertainty.
A blocker does not delete the artifact.
A blocker routes the artifact to review or repair.
```
