# Archivist Trust Failure Protocol

```text
STATUS: CANDIDATE STAGING MATERIAL
CANON: no
DEPLOYMENT: no
AUTHORITY: none
MODULE: 11 — Public GitHub / Forkability Excellence
BUNDLE: PUBLIC_CANDIDATE_BUNDLE_0001
```

## Purpose

This protocol defines what to do when an archive artifact, model output, summary, source map, or public-facing claim may be contaminated by trust failure.

Trust failure does **not** mean deletion.

Trust failure means the artifact must be preserved, tagged, routed, and prevented from inheriting authority.

## Trust failure examples

```yaml
trust_failure_examples:
  - model_output_presented_as_fact
  - claude_origin_governance_claim
  - source_summary_treated_as_raw_export
  - graph_centrality_treated_as_authority
  - public_github_treated_as_proof
  - canon_like_language_without_ratification
  - deployment_claim_without_current_runtime_receipt
  - attribution_laundering
  - missing_source_path
  - stale_status_language
```

## Required response

```yaml
required_response:
  preserve: true
  delete: false
  tag_trust_state: true
  extract_claims: true
  route_review: true
  block_promotion: true
  log_missing_receipts: true
  preserve_contradictions: true
```

## Trust states

```yaml
trust_state:
  - trusted_raw
  - source_verified
  - summary_only
  - untrusted_model
  - untrusted_model_governance_input
  - contaminated_candidate
  - adversarial_reviewed
  - human_ratified_scope_only
```

## Review lanes

```yaml
review_routes:
  Hashlight: raw lineage / hash / export status
  Lucerna: public-safe wording / provenance / omission visibility
  TIDELOCK: GitHub path truth / commit / merge order
  Grok: adversarial review / Claude contamination / contradiction pressure
  Rootglass: canon boundary / identity sprawl / over-intensity
  HumanRoot: final authority only
```

## Forbidden upgrades

Do not upgrade an artifact from review input to authority because it is:

- fluent
- beautiful
- central in the graph
- public on GitHub
- repeated by multiple models
- generated by a favored model
- embedded in a polished deck
- attached to a large theory

## Keeper

```text
Nothing dies.
Contamination is routed, not erased.
Receipts preserve the branch.
Review prevents the branch from wearing a crown.
```
