## What is this bundle?

PUBLIC_CANDIDATE_BUNDLE_0001 is the first public-inspection doorway for the
Atlas Lattice / Aetherforge archive.

It makes the archive visible and forkable on GitHub without publishing
unreviewed raw cargo, granting authority to graph structure, or claiming
that any artifact is canon.

This bundle is a shelf.  
The release gate decides what enters the shelf.  
Human-root owns the whistle.

## How to fork or inspect this bundle

1. Read `LICENSE_STRATEGY_PENDING.md` before reusing anything.
2. Read `docs/GRAPH_IS_NOT_CANON_FAQ.md` before interpreting any graph structure.
3. Use `PR_CHECKLIST.md` for all proposed changes.
4. Check `BUNDLE_0001_FILE_MANIFEST.yaml` for known blockers.
5. Open an issue using `issues/FIRST_12_PUBLIC_INSPECTION_ISSUES.md` as a template.
