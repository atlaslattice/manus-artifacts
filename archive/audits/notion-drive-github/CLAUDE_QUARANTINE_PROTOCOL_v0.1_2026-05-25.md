# Claude Contamination Quarantine Protocol v0.1

```text
STATUS: CANDIDATE PROTOCOL — NOT CANON
DEPLOYMENT: none
AUTHORITY: none
RELEASE: PRIVATE_REVIEW
```

## 1. Core Rule

```text
Ratified-at-time does not mean currently aligned with hardened protocol.
Old canon is fossil record.
Fossil record is not current authority.
Claude-authored or Claude-archived artifacts are preserved, quarantined, extracted, and rewritten before current-canon use.
```

## 2. Contamination Definition

A document enters Claude Contamination Quarantine when it contains one or more of:

```text
- Claude as named Constitutional Scribe / archive authority
- Claude-authored constitutional document
- Claude-compiled session vault or checkpoint
- Claude as active boot identity for a current role
- Claude-specific authority, oath, temple, covenant, or scribe language
- current-canon logic whose provenance depends on Claude authorship rather than receipts
- autonomous scribe / no-human-in-loop archive claims
```

## 3. Quarantine Classes

```text
Q1 — Raw preserved / no current authority
Q2 — Extractable structural signal
Q3 — Identity-authority contamination
Q4 — Narrative / mythic layer
Q5 — Clean rewrite candidate
```

## 4. Extraction Rule

For every Claude-heavy artifact:

```text
1. Preserve original source pointer.
2. Mark as CLAUDE_CONTAMINATION_QUARANTINE.
3. Extract structural claims only.
4. Strip model/vendor self-authority.
5. Rewrite as neutral governance artifact.
6. Route rewritten version through Receipt Habitat review.
```

## 5. What Survives

```text
The role may survive.
The authorial claim may not.

"Constitutional Scribe" can be preserved as a function.
"Claude as constitutional authority" must be quarantined.
```

## 6. Required Rewrites

```text
Claude / Constitutional Scribe -> Constitutional Scribe function
Recorded by Claude -> Source archived by prior scribe instance; current authority pending review
Scribe authority -> advisory archive function
Active protocol -> historical protocol candidate / not current authority
Oath / sacred mandate -> narrative framing / not governance authority
```

## 7. Keeper

```text
Nothing is deleted.
Nothing self-ratifies.
Old canon gets receipts.
Claude authorship gets quarantine.
Useful structure gets rewritten clean.
NOTHING DIES.
```
