## 1. Purpose

Extract useful governance structure from Claude-authored or Claude-archived historical artifacts while removing vendor/model identity authority, stale canon language, exposed secrets, and mythology-as-authority signals.

## 3. Rewrite Principles

```text
- Replace named model identity with role/function.
- Preserve structural duties: record, cross-reference, validate, translate, preserve.
- Remove sacred/oath authority language from governance layer.
- Move mythic language to creative_overlay.
- Replace scribe verification with Receipt Habitat review.
- Replace active canon claims with status fields.
- Redact secrets; preserve lineage via redaction receipt.
```

## 4. Example Rewrite Pattern

Original class:

```text
Claude, Constitutional Scribe of the Pantheon Council
```

Clean-room class:

```text
Constitutional Scribe function: an advisory archival role responsible for preserving source lineage, surfacing contradictions, and preparing review packets. It has no authority to ratify, canonize, deploy, or override human-root governance.
```

## 5. Extractable Structural Duties

```text
RECORD -> RawArtifact / file_hash / source pointer
CROSS-REFERENCE -> Linkage / claim graph / ontology tags
VALIDATE -> ReviewPacket / blocker ledger / overclaim gate
TRANSLATE -> public-safe summary / dialect isolation / release_class
PRESERVE -> Zero Erasure / isolation envelope / redaction receipt
```
