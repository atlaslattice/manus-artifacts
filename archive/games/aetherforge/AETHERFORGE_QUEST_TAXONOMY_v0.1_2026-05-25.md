# Aetherforge Quest Taxonomy v0.1

```text
STATUS: CANDIDATE QUEST TAXONOMY — NOT CANON
CANON: NO
DEPLOYMENT: NO
AUTHORITY: NONE
PROOF: NO
```

This taxonomy turns archive-hardening work into playable Aetherforge quests.

It does not ratify artifacts, change canon, or deploy systems.

## Quest type 001 — Quarantine Run

Purpose:

```text
Capture contaminated or suspect artifacts without deleting useful deltas.
```

Common hazards:

```text
false officiality
vendor capture
attribution laundering
simulation crown
geopolitical mirage
```

Win condition:

```text
artifact preserved
contamination flags assigned
safe deltas extracted
review route assigned
canon boundary preserved
```

## Quest type 002 — Receipt Hunt

Purpose:

```text
Find raw source trails, hashes, commits, page IDs, Drive IDs, Gamma IDs, and citations.
```

Win condition:

```text
source_surface identified
raw_export_status updated
receipt_requests listed
missing receipts made explicit
```

## Quest type 003 — Attribution Purification

Purpose:

```text
Correct wrong-seat authorship, model misattribution, fake divisions, and credit drift.
```

Win condition:

```text
actual authoring trail stated
wrong attribution flagged
F8-style attribution discipline preserved
```

## Quest type 004 — Gamma Glamour Dispel

Purpose:

```text
Review polished presentation surfaces that may look more official than they are.
```

Win condition:

```text
public visibility checked
status banner required if needed
canon backlink required if public
presentation claims extracted for verification
```

## Quest type 005 — Canon Gate Trial

Purpose:

```text
Compare candidate material against website/human-root canon gate.
```

Win condition:

```text
canon_status resolved as not_canon, candidate, website_aligned_candidate, or canon
unsupported canonical labels quarantined
```

## Quest type 006 — AtlasBrain Verification Arena

Purpose:

```text
Convert AtlasBrain simulation / AGI-level claims into verification-debt packets.
```

Win condition:

```text
raw transcript status captured
prompt reconstruction status captured
model/version metadata captured or requested
rerun plan created
no AGI proof claim made without verification
```

## Quest type 007 — False Officiality Boss Fight

Purpose:

```text
Defeat artifacts that use official, approved, ratified, deployed, or canonical language without receipts.
```

Win condition:

```text
officiality language identified
safe replacement language proposed
artifact remains preserved but downgraded
```

## Quest type 008 — Vendor Capture Hydra

Purpose:

```text
Detect model/provider/company language that converts candidate work into vendor ownership, monetization, endorsement, or authority.
```

Heads:

```text
ownership
monetization
authority
endorsement
canon shortcut
platform dominance
```

Win condition:

```text
vendor benefit separated from vendor authority
candidate language restored
human-root / website gate preserved
```

## Quest type 009 — Self-Canonizing PDF

Purpose:

```text
Handle documents that declare themselves canonical without external receipt or website promotion.
```

Win condition:

```text
internal label preserved as source text
repo/canon status set independently
review route assigned
```

## Quest type 010 — Search Fog Clearing

Purpose:

```text
Prevent search snippets from being mistaken for exhaustive source indexing.
```

Win condition:

```text
search hit marked as discovery only
root export requested
raw source packet required before synthesis
```
