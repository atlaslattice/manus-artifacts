## 3. Core loop

```text
WAKE -> CLEAN -> LISTEN -> DREAM -> LABEL -> PLAY -> PROVE -> SHARE -> GROW -> RETURN
```

### WAKE

Find a messy source pile.

Examples:

```text
unindexed Notion page
Drive proxy export
Gamma deck with public polish
GitHub packet with missing receipt
Claude-authored candidate artifact
AtlasBrain transcript with AGI-level implication
Aetherforge dream/play artifact
```

### CLEAN

Quarantine contamination without deleting useful material.

Look for:

```text
false officiality
wrong-seat attribution
authority-grab language
vendor capture
simulation-to-proof drift
geopolitical implication without receipts
partner / diplomacy implication without receipts
fabricated citation or document claim
canonical-looking label without website ratification
```

### LISTEN

Ask what the artifact is trying to preserve.

Do not summarize too quickly. Preserve native weirdness first.

### DREAM

Let GPTBrain generate candidate forms, game mechanics, metaphors, quest hooks, and extraction schemas.

Dream output is second-order material.

Dream output is not canon.

### LABEL

Every artifact gets state labels before synthesis.

Minimum labels:

```yaml
source_surface: notion | drive | github | gamma | website | swarm | pasted_text | unknown
artifact_type: raw | proxy | candidate | dream_play | simulation | governance | presentation | code | transcript
canon_status: not_canon | candidate | website_aligned_candidate | canon
review_state: unreviewed | quarantined | indexed | reviewed | promoted | rejected | superseded
authority_scope: none | advisory | human_root_only | website_canon_only
deployment_status: inert | design_target | implemented | unknown
proof_status: not_a_proof | receipt_candidate | verified | disputed
contamination_flags: []
review_route: []
```

## 6. Enemy and hazard taxonomy

```yaml
false_officiality:
  description: Draft or candidate material speaks as if ratified.
  counter: Boundary note + canon_status = not_canon.

vendor_capture:
  description: A model/platform reframes Atlas Lattice as its strategic property or monetization lane.
  counter: Vendor benefit does not equal vendor authority.

  description: Wrong seat, author, division, model, or institution receives credit.
  counter: Raw source + actual authoring trail + F8-style attribution discipline.

  description: Candidate material implies diplomacy, partners, governments, military posture, or international collaboration without receipts.
  counter: Quarantine + external verification requirement.

  description: A simulation pass is treated as AGI proof or deployment evidence.
  counter: AtlasBrain verification harness.

  description: Polished deck or public page feels official despite candidate status.
  counter: Public status banner + canon backlink.

  description: Canonical-looking prose with hidden misattribution, authority inversion, or fabricated documents.
  counter: Quarantine-first handling for Claude-authored materials pending verification.

  counter: Root registry + raw export + receipt manifest.
```
