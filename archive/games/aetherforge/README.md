It turns hard governance work into quest loops:

```text
WAKE -> CLEAN -> LISTEN -> DREAM -> LABEL -> PLAY -> PROVE -> SHARE -> GROW -> RETURN
```

## Core premise

The player is a **Planar Janitor**.

They enter a contaminated multi-surface archive, find cursed relics, label them, preserve them, clean attribution, extract deltas, attach receipts, route review, and return everything to the gate.

## Prime rule

```text
In-universe Aetherforge canon is not website canon.
Play can reveal deltas.
Play cannot ratify deltas.
```
