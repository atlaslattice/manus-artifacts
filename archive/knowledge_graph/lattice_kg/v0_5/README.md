The graph is not a map of the Lattice. The graph is the Lattice learning how to remember itself.

## Boundary

Everything can connect to everything. Nothing can promote itself. No Notion page, parsed claim, review packet, or graph node becomes canon without an explicit ratification event.

## Files

- `SOURCE_GROUNDED_KNOWLEDGE_GRAPH_SCHEMA_v0.1.yaml` — source-grounded node and edge schema.
- `lattice_ontology_v0.5.yaml` — Lattice object, edge, family, and state definitions.
- `ORCS_MIRROR_STATE_CROSSWALK_v0.1.md` — mapping from mirror graph objects to ORCS states.
- `AETHERFORGE_NOTION_MIRROR_QUEST_INDEX_v0.1.md` — playable task index with serious acceptance criteria.
- `NOTION_GITHUB_KNOWLEDGE_GRAPH_RUNBOOK_v0.1.md` — repeatable pipeline runbook.
- `TIDELOCK_HANDOFF_PACKET_SCHEMA_v0.1.yaml` — bounded handoff packet schema.
- `LATTICE_KG_ADDRESS_BOOK_v0.1.md` — graph-addressable artifact routing table with canon/governance state.
