Make it fun. Then make it checkable.

## Quest classes

- `Cartographer`: discovers and inventories source roots.
- `Archivist`: preserves raw exports and receipts.
- `Quarantine Smith`: labels contaminated material and blocks authority laundering.
- `Graph Weaver`: creates source-grounded nodes and edges.
- `Receipt Knight`: ties sources to GitHub issues, PRs, checksums, and reviews.

## Difficulty levels

- `training`: one record, one source, one safe check.
- `standard`: one Notion page from raw receipt to parsed packet.
- `elite`: conflict, duplicate, privacy, or crosswalk routing required.
- `boss`: batch work where false completeness is the main enemy.

## Reward types

- `receipt`: durable GitHub trace.
- `clarity`: uncertainty reduced without overclaiming.
- `shield`: contaminated source safely preserved.
- `bridge`: issue/PR/review linkage established.
- `song`: Aetherforge framing added with serious acceptance criteria.

## Boss tasks

- Build source inventory without treating discovery as completeness.
- Mirror raw exports without parsing over them.
- Route summary-only material into quarantine.
- Prove every claim reaches a `derived_from` source path.

## Side quests

- Add checksum when available.
- Link duplicate roots instead of deleting them.
- Add next safest action to every blocked record.
- Convert a review outcome into an ORCS state without ratification laundering.

## Rest-cycle quests

- Re-read blockers.
- Verify no file claims canon by location.
- Confirm all fun names have sober acceptance criteria.
- Stop when raw evidence is missing.

## Rule

Fun framing does not grant canon. Every mirror/graph task must carry serious acceptance criteria and playful framing separately.
