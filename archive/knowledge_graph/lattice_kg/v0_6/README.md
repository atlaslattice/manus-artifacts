# Lattice Knowledge Graph v0.6

> *One 12D octopus hypercube — not a bunch of legos.*

This is the unified knowledge-graph substrate for the Atlas Lattice.
All 12 dimension faces are integrated into one addressable, traversable,
integrity-gated lattice.

## Pipeline

```bash
# Build / refresh the index
python scripts/build_lattice_global_index.py --report

# Validate all 6 integrity gates
python scripts/validate_hypercube_integrity.py

# Query the lattice
python scripts/build_lattice_global_index.py --query "governance"
```

## Integrity Gates

Six gates enforce the "one organism" invariant:

| Gate | Rule |
|------|------|
| G01 | No orphan nodes |
| G02 | No duplicate artifact IDs |
| G03 | Graph connected (no isolated subgraph) |
| G04 | No schema drift |
| G05 | All 12 dimensions represented |
| G06 | All cross-link targets resolve |

## Relation to v0.5

v0.6 extends v0.5:
- Adds explicit `dimension_id` field (D01–D12) to every node
- Adds `cross_links` minimum requirement (≥ 1 per node)
- Adds the build + validation pipeline
- Adds the unified query surface

All v0.5 schemas and YAML definitions remain valid; v0.6 adds the integration
layer that ties them into one hypercube.
