> *One organism. Twelve dimensions. Every artifact mutually addressable.*

traversing the Atlas Lattice knowledge graph.  The lattice is **not** a
collection of isolated stacks — it is one 12-dimensional hypercube where

## 🧩 Integrity Gates

Before merging, run:

```bash
# 1. Rebuild index
python scripts/build_lattice_global_index.py

# 2. Validate integrity
python scripts/validate_hypercube_integrity.py
```

Six gates must all pass:

| Gate | Description |
|------|-------------|
| G01 | No orphan nodes |
| G02 | No duplicate artifact IDs |
| G03 | Graph connected (no isolated subgraphs) |
| G04 | No schema drift |
| G05 | All 12 dimensions represented |
| G06 | All cross-link targets exist |
