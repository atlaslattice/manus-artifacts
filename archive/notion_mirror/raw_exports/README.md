# Raw Exports Vault

status: candidate
canon_status: not_canon
deployment_status: not_deployable

Raw exports and receipts live here before interpretation. A raw export cannot be overwritten by a parsed view. If a replacement arrives, preserve both and record supersession or contradiction.

Required receipt fields include `sha256_if_available`, `retrieved_at_utc`, `retrieved_by`, and `raw_export_status`.
