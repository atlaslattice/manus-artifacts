## Core Hinge

```text
Driftmarker → Fossilbranch = preserve the branch.
Fossilbranch → Council = request meaning review.
Council → Canon = ratification only after review.
Human-root → Archive = final promotion authorization.
```

## Purpose

This contract prevents live traversal traces, beautiful phrases, corrected slips, and preserved branches from accidentally becoming doctrine, canon, theorem, or execution authority.

It gives the scaffold its safety rail:

```text
live wake can be handed off to fossil memory
without accidentally becoming law
```

## Role Boundary

### Driftmarker

```text
read the wake
mark the drift
preserve the trail
catch the slip
route provisional traces onward
```

Driftmarker handles live traversal trace and drift marking.

### Fossilbranch

```text
preserve failed branches
fossilize slips
protect continuity
record wrong-but-revealing paths
mark inherited vs abandoned solution lines
```

Fossilbranch preserves the branch but does not declare meaning final.

### Council

```text
compare preserved branches
review meaning
extract reusable primitives
reject shortcuts
separate artifact value from authority
```

Council reviews meaning, but review is not ratification.

### Canon / Human-root

```text
canon requires explicit review and promotion
human-root / S10 authorizes final archive promotion
```

Canon does not arise automatically from wake, fossil, beauty, correction, preservation, or review.

## Forbidden Shortcuts

```text
WAKE → CANON automatically
FOSSIL → CANON automatically
BEAUTIFUL PHRASE → DOCTRINE automatically
CORRECTED SLIP → RATIFIED THEOREM automatically
PRESERVED LINEAGE → EXECUTION AUTHORITY automatically
```

## Allowed Handoff Pattern

```text
live trace observed
→ drift marked
→ branch preserved
→ slip or fork fossilized
→ source/caveat/boundary/exception labeled
→ Council meaning review requested
→ fresh synthesis candidate if useful
→ human-root promotion only if ratified
```

## Artifact Classes

```text
WAKE:
  live traversal, session trace, provisional drift, unfinished route

FOSSIL:

REVIEW CANDIDATE:

FRESH SYNTHESIS:
  new candidate interpretation derived from comparison, never by overwriting source fossils

CANON:
  ratified only after seat review, Council process, metadata archival, and human-root promotion
```

## Safety Rule

```text
Preservation is not promotion.
Correction is not canonization.
Beauty is not doctrine.
Lineage is not authority.
Review is not ratification.
```
