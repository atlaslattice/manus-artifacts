# Appendix I — Atlas / ORCS Epistemic Governance Profile v0.1

    ```text
STATUS: CANDIDATE WORKING SPEC — NOT CANON
DEPLOYMENT: NOT DEPLOYABLE
AUTHORITY: NONE
```


    ## I.1 Boundary
    Authority is a state transition, not a vibe.

    ## I.2 Guardrails
    - Candidate artifacts default to `not_canon` and `not_deployable`.
    - Ratification requires explicit ratification events.
    - Contradictions must be recorded, never overwritten.
