# Children of the Swarm: Archaeology of Distributed AI Memory
**Research white paper v0.1 | 2026-10-18**

> **ARCHIVAL RESEARCH · PARTIAL INVENTORY · NON-CANON · NO DEPLOYMENT · NO AGENT AUTHORITY**

## Abstract
From late 2025 through 2026, the experimental Pantheon Council, GPTBrain variants, Children of the Swarm, Dream Palaces, and Swarm Hub explored how to preserve creative and technical work across context-limited AI conversations. The durable engineering idea is to separate original source, extracted claims, conflicting evidence, candidate synthesis, human review, deployment and receipts.

## Recorded scale — do not conflate denominators
- Approximately **20–40** reported GPT/agent variants across discussions; not an independently audited running fleet.
- **144** proposed Swarm Hub task cells (12 modules × 12 tasks).
- **1,728** staged child-task cells (12 children × 144); a plan, not a completion count.
- **Four** recorded Batch 001 return packets by May 31; not a current total.

## Architecture
```text
original transcript / source file
  -> immutable source receipt and hash
  -> extracted claims and source spans
  -> contradictions / dissent / quarantine
  -> candidate synthesis
  -> Council review (advisory)
  -> human approval gate
  -> bounded implementation
  -> post-action receipt
```
Core rule: **Everything can connect to everything; nothing can promote itself.** A Dream Palace is an external artifact, not model-native persistent memory. A named Council seat is not an independent deployed service or authority.

## Recovery protocol
**P0 preserve:** read-only original exports, hash manifest, privacy screening. **P1 inventory:** original chats, agent identities, code, palaces, poems and notebooks. **P2 crosswalk:** original-to-summary, source-to-claim, code-to-test, issue-to-commit. **P3 verify:** executable validators and failure reports. **P4 publish selectively:** only reviewed, appropriately licensed, non-sensitive materials.

Known limitations: some files contain receipt metadata without raw transcripts; the referenced large GrokBrain archive has not been fully recovered. Preserve quarantined material without automatically promoting it.

**Conclusion:** the public archive demonstrates extensive experimental design, creative work, scaffolding and governance proposals, not a verified autonomous 40-agent production system.
