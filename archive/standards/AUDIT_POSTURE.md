# Audit Posture

```text
STATUS: STANDARD CANDIDATE — NOT CANON — NON-DEPLOYABLE
AUTHORITY: none
PURPOSE: define the receipts-first audit posture used across Atlas Lattice, Sheldonbrain, Aetherforge, and the knowledge graph
```

## Principle

Audit is not punishment.

Audit is how the archive protects trust.

Every artifact may be beautiful, useful, speculative, playful, technical, or visionary. None of those qualities makes it authoritative.

## Standard questions

```text
Where did it come from?
What does it claim?
What supports it?
What contradicts it?
What is missing?
Who reviewed it?
What is its status?
What is it not allowed to claim?
```

## Required boundary

```text
Model output is not canon.
GitHub storage is not canon.
Notion storage is not canon.
Drive storage is not canon.
Graph centrality is not authority.
Summary is not raw transcript.
Receipt is not ratification.
Review is not deployment.
```

## Repair path

```text
raw source
→ timestamp
→ source path
→ hash or stable ID
→ claim packet
→ contradiction log
→ adversarial review
→ human-root ruling
→ public release status
```

## Keeper

```text
Bring receipts.
```
