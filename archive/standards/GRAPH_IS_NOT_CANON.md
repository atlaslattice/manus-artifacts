# Graph Is Not Canon

```text
STATUS: STANDARD CANDIDATE — NOT CANON — NON-DEPLOYABLE
AUTHORITY: none
PURPOSE: prevent knowledge graph structure from being mistaken for truth, canon, or authority
```

## Rule

The graph is a map of review pressure.

It is not a truth graph.

It does not decide canon.

It does not grant authority.

## Non-equivalences

```text
A graph edge is not a promotion.
A cluster is not canon.
A central node is not authority.
A coordinate is not permission.
A task is not execution.
A high-degree node is not a ruler.
A beautiful structure is not evidence.
```

## What the graph can do

```text
show sources
show claims
show contradictions
show missing receipts
show review routes
show raw-vs-summary distinctions
show provenance chains
show status mismatches
```

## What the graph cannot do

```text
ratify
canonize
deploy
grant authority
prove semantic truth
replace human-root review
```

## Keeper

```text
The graph shows where review is needed.
It does not decide what is true.
```
