# Documentation Excellence Seed

STATUS: SEED — NOT CANON

## Criteria (candidate)

1. Every artifact has a provenance header.
2. Every claim has a receipt reference.
3. Every doc is indexed in docs/ARCHIVE_INDEX.md.
4. Every public doc has a review_state field.
5. Dead links are caught by CI.
6. Docs site auto-deploys via MkDocs.
