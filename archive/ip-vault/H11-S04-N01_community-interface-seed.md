# Community Interface Seed

STATUS: SEED — NOT CANON

## Onboarding paths

1. **Quest contributor** — pick an open [good-first-issue](https://github.com/atlaslattice/manus-artifacts/issues?q=label%3A%22good+first+issue%22)
2. **Artifact submitter** — use the [Artifact Proposal](.github/ISSUE_TEMPLATE/artifact-proposal.yml) issue template
3. **Review contributor** — use the [Governance Review Request](.github/ISSUE_TEMPLATE/governance-review-request.yml) template
4. **IP vault contributor** — add an artifact to `archive/ip-vault/` with a provenance header and open a PR
