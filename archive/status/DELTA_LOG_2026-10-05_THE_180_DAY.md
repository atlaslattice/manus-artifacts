## Delta 001 — Alexandria 2.0 end-state clarified

Alexandria 2.0 is not merely an archive or search engine.

The intended end-state is a provenance-aware scientific discovery substrate that:

1. monitors verified scientific advances;
2. atomizes them into claims, evidence, mechanisms, constraints, inputs, outputs, maturity, and provenance;
3. multi-tags each advance across the 12×12×12 / 1,728-cell coordinate surface and broader dimensional metadata;
4. searches for cross-sphere mechanistic compatibility;
5. surfaces candidate compound applications from advances that may appear unrelated inside conventional disciplinary silos;
6. routes candidate unifications through adversarial review, simulation, human/domain review where consequential, and eventual experimental evidence;
7. feeds validated outcomes back into the graph so discovery compounds recursively.

Core query:

```text
What became possible today that was not possible yesterday?
```

## Delta 002 — Epistemic routing is the differentiator

The value proposition is not "more information."

It is better routing among:

- primary evidence
- replicated findings
- measured results
- simulations
- proposals
- disputed claims
- superseded claims
- quarantined material
- missing receipts
- unresolved contradictions

Claims, rather than whole documents, should carry evidence status.

Embedding similarity is useful for discovery, but the deeper layer should be a typed causal/mechanistic graph capable of identifying things that physically compose rather than merely sound related.

## Delta 004 — First convincing Alexandria MVP defined

A useful MVP does not require complete population of all 1,728 cells.

Candidate demonstration:

- ingest 100–500 verified breakthroughs;
- map them across 30–50 well-defined spheres;
- attach structured mechanism / input / output / materials / operating-regime / maturity / evidence metadata;
- run compatibility search;
- produce at least one non-obvious candidate synthesis with full citations, explicit unresolved constraints, and no overclaim of validation.

Success criterion:

```text
AI proposes a genuinely non-obvious, physically coherent cross-domain hypothesis
and can explain exactly which independent advances made it newly plausible.
```
