# Explainer 001 — The Graph Is the Tape

```text
STATUS: PUBLIC EXPLAINER CANDIDATE — NOT CANON
DEPLOYMENT: none
AUTHORITY: none
AUDIENCE: nontechnical readers
```

## The short version

Atlas Lattice is a public knowledge graph project for making a large archive easier to inspect.

It does not start by declaring what is true.

It starts by asking:

```text
What exists?
Where did it come from?
What does it claim?
What evidence supports it?
What contradicts it?
What is missing?
Who should review it next?
```

That is why we say:

```text
The graph is the tape, not the trophy.
```

## What “the graph” means

A graph is a map of relationships.

In this project, a graph can connect:

```text
source documents
raw exports
summaries
claims
evidence anchors
missing receipts
contradictions
review findings
decisions
tasks
```

The graph helps people see how work is connected.

It does not decide that something is true just because it is connected.

## Why this matters

Large archives get messy quickly.

Files get copied. Summaries get mistaken for originals. Drafts sound final. AI outputs can look confident even when they are only guesses. Old notes can contain useful ideas mixed with outdated language.

A public knowledge graph helps by separating these layers:

```text
source ≠ summary
claim ≠ evidence
review ≠ ratification
GitHub file ≠ canon
AI output ≠ authority
```

## What GitHub is for

GitHub is the public receipt shelf.

It lets people inspect files, schemas, issues, changes, pull requests, and history.

But GitHub does not magically make a file canon. It only makes the file easier to review.

## What OpenAI/GPTBrain is for

OpenAI/GPTBrain is treated as a reasoning and extraction lane.

It can help:

```text
extract claims
classify sources
find missing receipts
spot contradictions
route review
create candidate graph packets
```

It cannot:

```text
ratify canon
deploy the system
grant authority
claim official endorsement
```

## What human-root is for

Human-root is the final authority gate.

The graph can show review pressure. Human-root decides what, if anything, graduates.

## What “public candidate” means

Public candidate means:

```text
safe enough to inspect
not final
not canon
not deployed
not authority
```

That makes the work forkable without pretending it is finished.

## Keeper

```text
Make the archive visible.
Make the claims inspectable.
Make the evidence traceable.
Make overclaims harder.
Make truth slower and stronger.
```
