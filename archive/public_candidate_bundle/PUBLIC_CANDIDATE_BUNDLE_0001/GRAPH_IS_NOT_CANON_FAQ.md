# Graph Is Not Canon — FAQ

```text
STATUS: PUBLIC FAQ CANDIDATE — NOT CANON
DEPLOYMENT: none
AUTHORITY: none
```

## Is the Atlas Lattice knowledge graph canon?

No. The graph is not canon by default.

The graph maps artifacts, claims, evidence anchors, missing receipts, contradictions, review findings, and candidate decisions. It does not decide what is true.

## Does a graph edge promote an artifact?

No.

```text
A graph edge is not a promotion.
A cluster is not canon.
A central node is not authority.
```

## Does GitHub make something canon?

No. GitHub is a public receipt and version-control surface. A file in GitHub can be useful, reviewable, and public without being canon.

## Does OpenAI/GPTBrain make something official?

No. OpenAI/GPTBrain is treated here as a reasoning, extraction, evaluation, and routing lane. It may generate candidate graph packets, but it does not ratify, deploy, authorize, or imply OpenAI endorsement.

## What does human-root do?

Human-root decides what, if anything, graduates beyond candidate status. Public-safe publication is not the same as canon promotion.

## What about dream/play outputs?

Dream/play outputs can produce useful deltas, motifs, task candidates, and review targets. They are not evidence by themselves.

## What about Claude-originated artifacts?

Claude-originated governance material is preserved but routed to adversarial review. Claude cannot be sole/root archivist or source of authority for high-impact material.
