# Code of Practice Cadence

> Defines how Atlas Lattice's code of conduct and community norms are reviewed, refreshed, and enforced.

status: candidate

---

## What Is the Code of Practice?

The Atlas Lattice Code of Practice is the set of community behavioral norms that apply to all contributors, collaborators, and community members in all community spaces (GitHub, Discussions, issues, PRs, and any live events).

Current norms are documented in `archive/governance/CONDUCT_NORMS_POLICY.md`.

---

## Annual Review Cadence

The Code of Practice is reviewed annually:

| Step | Action |
|------|--------|
| 1. Gather input | Open a GitHub Discussions thread for community input (30 days before review) |
| 2. Assess incidents | Review any code of conduct incidents from the past year |
| 3. Draft changes | Council drafts proposed changes based on input + incidents |
| 4. Community comment | Draft is open for 14 days of public comment |
| 5. Ratify | @atlaslattice ratifies the final version |
| 6. Publish | Updated norms go live; community is notified via Announcements |

---

## Incident Response

When a code of conduct violation is reported:
1. Reporter contacts @atlaslattice directly (GitHub: private message, or issue DM)
2. @atlaslattice acknowledges within 48 hours
3. Investigation within 7 days
4. Decision communicated to reporter and (if appropriate) to the community

Outcomes range from a private warning to contributor removal, depending on severity.

---

## Transparency

While individual incidents are confidential, the annual governance report includes an aggregate count:
- Code of conduct reports received: N
- Reports resolved: N
- Outcomes: [range, no individual identification]

---

## External Standards

The Atlas Lattice Code of Practice is inspired by:
- Contributor Covenant v2.1
- Open Source Initiative community guidelines
