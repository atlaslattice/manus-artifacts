# Contributor Journey Map

> Maps the complete contributor journey from discovery to long-term contribution.

status: candidate

---

## Journey Stages

### Stage 1: Discovery

**Entry points:**
- GitHub search for knowledge graph / open-source archive projects
- Direct link from @atlaslattice's profile or blog
- Referral from another contributor

**What the contributor sees first:**
- `README.md` — the public face; explains mission, quick-start, and links
- GitHub topics: `knowledge-graph`, `open-source`, `aetherforge`
- Stars and activity signals

**Goal at this stage:** Understand what Atlas Lattice is and why it matters.

---

### Stage 2: Orientation

**Resources:**
- `docs/NEWCOMER_FAQ.md` — answers the top 10 questions new contributors ask
- `docs/GOVERNANCE_ONBOARDING_GUIDE.md` — how decisions are made
- `CONTRIBUTING.md` (planned) — how to make a contribution
- `docs/GLOSSARY.md` — shared vocabulary

**Goal at this stage:** Know enough to pick a first contribution.

---

### Stage 3: First Contribution

**Entry points for first contributions:**
- Issues labeled `good first issue` (see First Issue Fast Lane)
- Wave N task board — pick an unchecked task and open a PR
- Fix a typo, broken link, or missing alt text found while reading

**Support:**
- `docs/NEWCOMER_FAQ.md`
- GitHub Discussions
- The welcome bot message on first PR

**Goal at this stage:** Successfully merge one PR.

---

### Stage 4: Regular Contributor

**Signs of regular contribution:**
- Multiple merged PRs
- Participates in issue discussions
- Runs CI locally before submitting

**Support:**
- Contributor recognition (see Contributor Recognition Loop)
- Mentorship pairings (see Mentorship Playbook)
- Office hours (see Office Hours Protocol)

**Goal at this stage:** Contribute to multiple waves; earn domain familiarity.

---

### Stage 5: Domain Owner

**Signs:**
- Takes ownership of a test domain (see Test Ownership Matrix)
- Reviews PRs in their area
- Proposes RFC-level changes

**Support:**
- Council review access
- Listed in CODEOWNERS

**Goal at this stage:** Maintain a section of the repository with high quality.

---

### Stage 6: Council Member

By ratification of @atlaslattice. Council members participate in ratification decisions and shape the repository's direction.

---

## Friction Audit

The contributor journey is audited annually for friction points:
- Where do new contributors get stuck?
- Which docs are most frequently visited but also most frequently have open issues?
- What is the average time from first issue comment to first merged PR?
