# Monthly Community Update Template

> Template for the monthly community update posted in GitHub Discussions.

status: candidate

---

## Update Template

```markdown
# Atlas Lattice — [Month YYYY] Community Update

📣 *Posted by @atlaslattice or council member — [Date]*

---

## 🌐 What We Shipped This Month

[Summary of waves completed, documents created, major milestones]

## 📊 Campaign Progress

- Overall: N/144 missions complete
- This month: +N missions
- Current wave: Wave N — [Name]

## 🕸️ Knowledge Graph Stats

- Total nodes: N
- Total edges: N
- New this month: +N nodes, +N edges
- Orphan rate: N%

## 🛡️ Quality Health

- CI pass rate: N%
- Open issues: N
- Issues resolved this month: N
- Flaky tests quarantined: N

## 👥 Contributors

Welcome to our new contributors this month:
- [List of first-time contributors]

Thank you to all who contributed:
- [List of all contributors with merged PRs]

## 🔮 What's Coming Next Month

[1-3 bullet points about the next wave or upcoming priorities]

## 💬 Discussion

Questions, reactions, suggestions? Reply below!

---

*Published monthly in the Announcements discussion category*
```

---

## Publishing Schedule

| Action | When |
|--------|------|
| Draft the update | Last 3 days of each month |
| Publish in Discussions | 1st Monday of each month at 09:00 UTC |
| Archive in repository | `archive/community/MONTHLY_UPDATE_YYYY_MM.md` |

---

## Community Update Metrics

Track monthly:
- Number of views (GitHub Discussions view count)
- Number of reactions (GitHub Discussions reactions)
- Number of replies
