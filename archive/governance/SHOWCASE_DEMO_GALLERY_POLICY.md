# Showcase and Demo Gallery Policy

> Defines the Atlas Lattice showcase gallery for featuring community-built tools, visualizations, and research.

status: candidate

---

## Purpose

The showcase gallery celebrates what the community has built using Atlas Lattice data, schemas, and protocols. It serves as:
- Social proof that Atlas Lattice has real-world value
- Inspiration for new contributors
- A record of community creativity

---

## Gallery Location

The showcase lives in GitHub Discussions (Show and Tell category) and is summarized in the monthly community update.

A curated selection is featured in `docs/SHOWCASE.md` (planned).

---

## Submission Process

To add a project to the showcase:
1. Post in GitHub Discussions → Show and Tell category
2. Include: project name, one-paragraph description, link, screenshot or diagram (optional)
3. A council member will feature it in the next monthly update

---

## Gallery Categories

| Category | Description |
|---------|-------------|
| KG Visualizations | Visual representations of the Lattice knowledge graph |
| Schema Implementations | Projects using Atlas/ORCS or other schemas from this repo |
| GPTDream++ Implementations | Tools implementing GPTDream++ protocols |
| Aetherforge Extensions | Extensions of the Aetherforge game concept |
| Research and Analysis | Papers, notebooks, or reports using Atlas Lattice data |
| Educational Content | Tutorials, videos, blog posts explaining Atlas Lattice |
