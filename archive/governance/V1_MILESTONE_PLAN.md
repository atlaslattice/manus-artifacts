# Milestone Plan to v1.0

> Defines the milestones and criteria for Atlas Lattice v1.0 — the world-class public launch.

status: candidate

---

## v1.0 Definition

**Atlas Lattice v1.0** is the first formal public release. It represents:
- All 144 governance/documentation missions completed (✅ done as of 2026-05-28)
- World-class scorecard ≥ 83% (600/720)
- Live, functional knowledge graph with public API
- Verified archival durability
- Public launch announcement

## v1.0 Acceptance Criteria

**Must have:**
- [ ] All 144 missions scored ≥ 3/5 individually
- [ ] Total scorecard score ≥ 600/720
- [ ] Functional KG index with ≥ 500 nodes
- [ ] All CI workflows implemented (not just documented)
- [ ] ≥ 5 external contributors with merged PRs
- [ ] Archival durability verified
- [ ] Press kit published
- [ ] Launch blog post published

**Nice to have:**
- At least 1 Tier 1 language translation (Spanish or Chinese)
- Open Data Export Packs v1 shipped as GitHub Release
- First academic paper citing Atlas Lattice
