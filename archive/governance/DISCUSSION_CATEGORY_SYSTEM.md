# GitHub Discussions Category System

> Defines the discussion category structure for Atlas Lattice's GitHub Discussions forum.

status: candidate

---

## Category Taxonomy

| Category | Emoji | Format | Use |
|---------|-------|--------|-----|
| Announcements | 📣 | Announcement | Official announcements from council (only council can post) |
| Q&A | 💬 | Q&A | Questions about the project; answers can be marked as accepted |
| Ideas | 💡 | Open | Feature requests, roadmap suggestions, design discussions |
| Show and Tell | 🎉 | Open | Share what you built with or inspired by Atlas Lattice |
| Office Hours | 🕐 | Open | Weekly async office hours thread |
| Mentorship | 🧑‍🏫 | Open | Mentorship pairing requests and discussion |
| Aetherforge | ⚔️ | Open | Game design, Aetherforge campaign discussion |
| KG Design | 🕸️ | Open | Knowledge graph architecture and design |
| Meta | 🔧 | Open | Discussion about the community itself |

---

## Category Rules

### Announcements
- Only council members can create announcements
- Announcements are pinned for their relevant period
- All contributors can comment

### Q&A
- The question poster should mark one answer as "accepted" when resolved
- Unanswered questions are eligible for the help-wanted label after 7 days

### Ideas
- Ideas should be explored in Discussions before being filed as issues
- Ideas with strong community support are elevated to RFC proposals

---

## Moderation

Discussion moderation follows the Code of Conduct (CONDUCT_NORMS_POLICY.md). Moderators:
- @atlaslattice (primary)
- Council members (secondary)

Posts that violate the Code of Conduct are removed and the poster is notified.

---

## Discoverability

All discussion categories appear in the GitHub Discussions tab. New categories require council approval via PR to this document.
