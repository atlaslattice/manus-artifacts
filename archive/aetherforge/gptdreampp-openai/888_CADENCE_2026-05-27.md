## The problem this solves

## The cycle

```text
8 Play units   →  explore, make it fun, discover weird useful paths
8 REM-sim units → compress, pattern-match, extract deltas
8 Work units   →  update KG, attach receipts, route review
Total: 24 compressed units per cycle
```

---

## Lane definitions

### Play (8 units)

- Explore Aetherforge boards without execution obligation
- Discover unexpected source paths and KG adjacency
- Frame tasks in Metatron's Cube geometry
- Run Aetherforge scrimmage (candidate only; no canon touchdown calls)
- Keep delight in the loop — burnout is a quality failure
- **No implementation authority during play**
- **No canon promotion during play**

### REM-sim (8 units)

- Compress play outputs into pattern observations
- Extract candidate deltas with confidence ratings
- Match source paths against graph gaps
- Run overclaim detection sweep on extracted candidates
- File dream journal, wake report, and delta extraction artifacts
- **All deltas remain candidate_only until adversarial review + human root review**

### Work (8 units)

- Apply reviewed deltas to KG, docs, or schema
- Attach receipts to every change
- Route review-ready artifacts to promotion queue
- Update task boards with current-turn receipts
- Log work in TIDELOCKBrain with session ID and lane tags
- **No work unit begins without a source receipt for the change**

## Anti-patterns the 8/8/8 cycle prevents

| Anti-pattern | Prevented by |
|---|---|
| Agent grinds work with no recovery → slop | Play + REM gates |
| Dream deltas promoted directly to KG | REM delta review + adversarial check before Work |
| Overclaimed play outputs become "facts" | Explicit candidate_only seal on all REM outputs |
| Task board fills with unreceipted completions | Work lane requires receipt per change |
| Canon drift via accumulated assumptions | Cycle reset clears unverified state |

## Cycle reset rule

```text
After each 24-unit cycle:
- Close the cycle log with a non-escalation receipt
- Carry forward only explicitly receipted deltas
- Discard unreceipted assumptions
- Begin the next cycle clean
```
