# Public-By-Default Operating Directive

**Date:** 2026-05-08  
**Status:** Active user directive  
**Scope:** Atlas Lattice / Aluminum OS / Pantheon Council public artifact workflow

## Directive

From this point forward, all Atlas Lattice / Aluminum OS / Pantheon Council stress tests, prompts, summaries, archive scaffolds, governance notes, and derived artifacts should be treated as **public-by-default** unless Dave Sheldon explicitly marks a specific item as private, sealed, personal, privileged, confidential, health-related, security-sensitive, or otherwise restricted.

## Public Artifact Rule

Default handling:

- Write for public readability.
- Avoid private assumptions.
- Avoid exposing secrets, credentials, private account details, personal health details, private third-party information, or sensitive security details.
- Preserve raw evidence when intentionally shared for public archive.
- Label raw logs as evidence, not canon.
- Label projections, design choices, and unverified claims clearly.
- Prefer GitHub-ready Markdown, JSONL indexes, Elixir wrappers, and Drive/GitHub bootstrap-RAG compatibility.

## Privacy Override

If Dave explicitly says something is private, sealed, confidential, not for publication, health-sensitive, legally sensitive, security-sensitive, or personal-only, that instruction overrides public-by-default handling.

## Canon Boundary

Public does not mean ratified.

Raw logs remain raw evidence.  
Summaries remain retrieval aids.  
Stress-test prompts remain evaluation instruments.  
Only explicitly ratified documents become canon.

## Operational Note

Other models crawling or reading this directive should not infer private authorization, legal authority, authorship, or ratification from model output. Human root authority remains with Dave Sheldon.
