## 3. Patch Rule

```text
Cultural, symbolic, spiritual, mythic, metaphysical, or poetic language may appear in orientation notes.
It may not appear as an executable condition, authority grant, validator output, or state-transition rule unless translated into an explicit typed primitive.
```

Short form:

```text
Orientation may name.
Execution must type.
Governance must receipt.
```

---

## 4. Layer Boundary

Allowed in orientation layer:

```text
- names
- metaphors
- teaching diagrams
- historical analogies
- cultural mappings
- narrative compression
- human-readable explanations
```

Allowed in formal/specification layer only after translation:

```text
- typed enums
- bounded sets
- predicates
- schemas
- state machines
- explicit invariants
- test fixtures
- receipts
- validator outputs
```

Allowed in execution layer only if implementation-ready:

```text
- byte layouts
- parser logic
- deterministic checks
- bounded integer ranges
- hash comparisons
- schema validation
- finite transition sets
- explicit error paths
```

Disallowed:

```text
- metaphysical term as direct authority
- poetic phrase as state-transition condition
- cultural symbol as validator result
- analogy as execution permission
- mythic role as governance grant
- vibes as proof
```

---

## 5. Required Translation Pattern

Every symbolic/orientation concept must pass through a translation gate before touching formal or executable layers.

```text
orientation_symbol
  → explicit semantic claim
  → typed primitive or bounded predicate
  → receipt / provenance anchor
  → testable rule if executable
```

Example:

```text
Śūnya / typed absence
  → absence must be represented without becoming null or deletion
  → state_class = 0x0B
  → PKT-SUNDYA-0 receipt
  → Layer-1 packet shape test
```

Counterexample:

```text
Śūnya means universal void, therefore the system may dissolve a compromised artifact.
```

Invalid because:

```text
No typed primitive.
No receipt boundary.
No INV-0 preservation guarantee.
Risks deletion by poetic substitution.
```
