**Purpose:** Define a systematic archive-wide audit protocol for identifying documents that look coherent or authoritative but are actually polluted by overclaim, misattribution, stale context, false canon status, continuity theater, corpus/control confusion, or unsupported synthesis.

## Working Name

Informal swarm nickname may remain user-side, but repo-facing title should stay clean and review-safe.

## Boundary

```text
This is an audit protocol, not a deletion protocol.
Do not erase bad documents.
Do not merge them away.
Do not silently rewrite.
Quarantine, crosswalk, annotate, and preserve lineage.
Fresh synthesis only after review.
```

## Target Failure Modes

```text
[ ] false canon implication
[ ] false deployment / runtime claim
[ ] native memory or continuity theater
[ ] model-authored document pretending seat endorsement
[ ] Manus corpus misread as executable control
[ ] GitHub receipt mistaken for ratification
[ ] summary mistaken for raw log
[ ] confidence without source refs
[ ] hallucinated repo paths / commit refs
[ ] stale source-of-truth assumptions
[ ] identity merge / lineage collapse
[ ] mythic metaphor literalized as implementation
[ ] safety/legal/medical/financial overclaim
[ ] hidden authority or autonomous-agent implication
```

## Proposed Scoring Dimensions

```text
1. Source integrity
2. Canon-status hygiene
3. Claim/evidence alignment
4. Attribution accuracy
5. Corpus/control separation
6. Continuity-theater risk
7. Deployment/runtime overclaim
8. Privacy/publication risk
9. Supersession/staleness risk
10. Repairability
```

## Output Classes

```text
PASS = sound enough for normal archive use
WARN = usable with caveats
QUARANTINE = preserve but do not cite as authority
OVERCLAIM MEDAL = high-confidence nonsense / severe overclaim / dangerous ambiguity
REPAIR_CANDIDATE = salvageable via fresh synthesis
SUPERSEDED = replaced by later verified artifact
```
