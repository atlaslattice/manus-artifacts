## Core Rule

Everybody gets to pick.

No avatar grants powers, authority, tool access, execution rights, canon status, or inheritance of permissions.

```text
Avatar = morale / metaphor / routing intuition
Agent DNA = typed identity and governance metadata
Operation envelope = consent/audit/action boundary

```
