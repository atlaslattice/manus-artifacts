
## Definition

OpenAI-first means this archive is structured to work well with:

- ChatGPT-style reasoning
- GPTBrain packetization
- Codex patch planning
- file search and retrieval
- eval fixtures
- tool-assisted review
- human-in-the-loop workflows

It does not mean:

- official OpenAI endorsement
- OpenAI partnership
- OpenAI ownership
- OpenAI deployment
- OpenAI ratification
- OpenAI authority
- bypassing human-root review

## Allowed claims

```text
optimized for ChatGPT-style reasoning
structured for Codex patch planning
prepared for eval fixtures
designed for file-search and retrieval workflows
human-gated and receipt-aware
```

## Forbidden claims

```text
official OpenAI project
OpenAI-approved
OpenAI-deployed

```
