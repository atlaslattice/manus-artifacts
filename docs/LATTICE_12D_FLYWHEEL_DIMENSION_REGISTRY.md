## Dimension notes

### D01 — House

Top-level domain or habitat family. Entry coordinate component: `H##`.

### D02 — Sphere

Semantic or operational container inside or across a House. Entry coordinate component: `S##`.

### D03 — Node

Addressable cell, artifact, claim family, experiment, prototype, or review target. Entry coordinate component: `N##`.

### D04 — Source / Lineage

Tracks where the node came from: raw source, repo path, chat export, document, commit, upload, or external reference.

### D05 — Claim / Semantic Content

Tracks what the node says or means, including strongest safe wording and overclaims to avoid.

### D06 — Evidence / Receipt Strength

Tracks support quality: raw receipt, hash, citation, test result, reproducible run, contradiction, or missing evidence.

### D07 — Review / Adversarial Status

Tracks review posture: unreviewed, needs receipts, needs adversarial review, reviewed public-safe, quarantined, or human-root review needed.

### D08 — Authority / Canon Boundary

Tracks whether the node is not-canon, candidate, fossil, council-reviewed, human-root adjudicated, or website canon.

### D09 — Deployment / Execution Boundary

Tracks whether the node is non-deployable, staged, gated, sandbox-only, executable only after gate, or deployed by explicit authorization.

### D10 — Temporal / Version State

Tracks draft/version lineage, supersession, active branch, fossil branch, contradiction branch, or current promoted surface.

### D11 — Resonance / Projection State

Tracks view/projection: graph, frequency, acoustic resonance, neuromorphic, matter-property, color-harmonic, invention archive, public release, or other projection.

### D12 — Conservation / Routing / Quarantine State

Tracks preservation and routing: preserve, compress, archive, quarantine, fork, inherit, recover, reject, or route to review. This is the INV-0 protection lane.
