# Stewardship Map
Status: Candidate
Date: 2026-05-26

This map assigns stewardship expectations across the six archive taxonomy domains.
It is a governance aid, not a substitute for formal decision rights.
Aetherforge uses this map to keep each ring of Metatron's Cube operational even when individual contributors rotate.

## Stewardship roles

- **Steward** — primary owner for quality, metadata hygiene, and review readiness
- **Backup** — continuity owner who can keep the domain moving during absence or overload
- **Review cadence** — minimum expected rhythm for proactive review

## Shared operating expectations

1. Every domain should have a named steward before promotion of new canon material.
2. Backup stewards should be able to explain the current priority queue and unresolved risks.
3. Review cadence is a minimum, not a maximum; urgent risks trigger immediate review.
4. Stewardship includes link integrity, metadata completeness, and public readability.
5. Cross-domain artifacts should identify one primary domain even when many domains are affected.

## Escalation model

- Domain issues are handled first by the primary steward.
- If the steward is unavailable, the backup becomes acting steward.
- If the matter affects canon authority, conflict resolution, or public trust, escalate to governance review.
- Final canon adjudication remains with @atlaslattice.

## Review rhythm by archive layer

| Layer | Expected owner behavior |
| --- | --- |
| Working draft layer | Triage weekly when active |
| Candidate layer | Review before public amplification |
| Canon layer | Audit quarterly and at every supersession event |
| Archived layer | Review only for lineage, access, or risk concerns |
| Deprecated layer | Keep warnings and replacement links current |

## Notes for public readers

Stewardship denotes maintenance accountability, not personal ownership of ideas.
It ensures the archive remains durable, transparent, and succession-safe as Aetherforge evolves.
