# Trust Charter v1
Status: Candidate
Date: 2026-05-26

The Manus archive exists to be inspectable, not merely impressive.
This charter states the public commitments that should govern how the repository is maintained, reviewed, and presented.
In Aetherforge terms, trust is the centerpoint that keeps all five rings of Metatron's Cube coherent.

## Charter commitments

### 1. Transparency

We will prefer open publication of artifacts, decision records, and governance rules whenever safety and legal constraints allow.
Status labels should be explicit so readers can distinguish candidate material from ratified canon.

### 2. Auditability

We will preserve enough structure, metadata, lineage, and decision logging for a third party to reconstruct how major claims and canon changes occurred.
Historical context should remain available unless a documented retention exception applies.

### 3. Open-source access

This repository is MIT licensed, public, and intended for durable public access.
Access should not depend on private relay tools when the canonical GitHub record can serve the same function.

### 4. Quality standards

Public artifacts should be coherent, linkable, attributable to a domain, and reviewable by readers who did not participate in their creation.
Quality means more than formatting: it includes provenance, navigability, and comprehensibility.

### 5. Canon integrity

We will not represent material as canon unless it has been ratified by the full council and adjudicated by @atlaslattice.
Candidate visibility is encouraged; canon inflation is not.

## Commitments to contributors

- We will keep governance rules legible and published.
- We will separate working hypotheses from authoritative doctrine.
- We will favor additive clarification over silent reinterpretation.
- We will preserve supersession chains where they matter for understanding.
- We will publish correction paths when material defects are found.

## Commitments to public readers

- You should be able to tell what the artifact is, when it changed, and what authority it holds.
- You should be able to trace high-impact claims to their evidence or decision context.
- You should be able to review this archive without relying on insider context.
- You should be able to see how Aetherforge priorities map to public outputs.

## What this charter does not do

This charter does not override the canon boundary, council review workflow, or retention policy.
It provides the public-facing trust posture those documents must uphold.

## Enforcement posture

Suspected breaches of this charter should trigger review under the governance incident response runbook.
Repeated failures should be tracked in the risk register and addressed in mission control cadence reviews.

## Versioning

This is v1 of the trust charter.
Revisions should preserve a clear changelog entry and should not weaken canon integrity without formal review.
