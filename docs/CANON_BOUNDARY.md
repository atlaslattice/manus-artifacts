# Canon Boundary Reference (Candidate)

## Canonical substrate

GitHub is the durable canonical substrate for this program.

## Non-canonical relay layers

Google Drive, Notion, and similar working vault tools may be used as relay or drafting surfaces, but they are not canon authorities.

## Canon status rule

No artifact is canon until:

1. Ratified by the full council, and
2. Adjudicated by @atlaslattice.

Until then, all artifacts should be treated as candidates.

## Operational guidance

- Prefer repository files as the source of truth for references and citations.
- When relay copies differ from GitHub, GitHub governs.
- Mark uncertain artifacts explicitly as candidate in public-facing docs.
