# How to Cite This Work

## Summary

Guidelines for citing Atlas Lattice artifacts, schemas, protocols, and specifications in academic papers, technical reports, and derivative projects.

---

## Citing the Repository

**General citation (APA style):**

> Sheldon, D. (2026). *Atlas Lattice: A public knowledge graph and constitutional AI substrate* [Software and documentation repository]. GitHub. https://github.com/atlaslattice/manus-artifacts

**BibTeX:**

```bibtex
@misc{atlaslattice2026,
  author       = {Sheldon, David},
  title        = {{Atlas Lattice}: A public knowledge graph and constitutional {AI} substrate},
  year         = {2026},
  publisher    = {GitHub},
  howpublished = {\url{https://github.com/atlaslattice/manus-artifacts}},
  note         = {MIT License}
}
```

## Citing Specific Files

When citing an individual specification or document, include:
1. The file path relative to the repository root
2. The Git commit SHA or tag for reproducibility (use `git log --oneline <file>` to find the relevant commit)

**Example:**

> Sheldon, D. (2026). *Rainbow Yin-Yang Hypercube Lattice Specification v2.1* [Candidate specification]. Atlas Lattice Foundation. Retrieved from `archive/architecture/RAINBOW_YIN_YANG_HYPERCUBE_LATTICE_SPEC_V2_1_COMPLETE_2026-05-20.md` at commit `<sha>`.

> **Tip:** Find the commit SHA for a specific file with `git log --oneline <path/to/file>`, then use the first column hash.

## Attribution in Derivative Works

If you build on schemas, protocols, or reference implementations from this repository, add the following acknowledgment to your project:

> This work builds on the Atlas Lattice open-source knowledge graph and constitutional AI substrate (https://github.com/atlaslattice/manus-artifacts), released under the MIT License.
