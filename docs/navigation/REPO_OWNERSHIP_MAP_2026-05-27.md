# Repository Ownership Map (Wave 2)

Ownership model for navigation and maintenance:

- **Council/Governance owners:** `council/`, `council-reviews/`, canon adjudication artifacts
- **Core architecture owners:** `aluminum-os/`, `sheldonbrain/`, `bazinga/`
- **Archive and evidence owners:** `archive/`, `archives/`, `manus-vault/`
- **Public-facing documentation owners:** `README.md`, `about/`, `projects/`, `docs/`, `research/`, `health/`
- **Engineering ops owners:** `.github/`, `scripts/`, `tests/`, `schemas/`, `fixtures/`

This map is candidate guidance until ratified.
