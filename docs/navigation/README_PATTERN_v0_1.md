# README Pattern v0.1 (Wave 2)

Use this section order for major-domain README files:

1. Title
2. Purpose
3. Scope
4. Key artifacts
5. How to verify
6. Cross-links
7. Status

## Minimal template

- **Purpose:** What this domain exists to do.
- **Scope:** What is included/excluded.
- **Key artifacts:** Main files/folders readers should open first.
- **How to verify:** Validation or review path.
- **Cross-links:** Connected domains.
- **Status:** candidate/canon and maintenance state.
