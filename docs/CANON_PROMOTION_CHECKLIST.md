# Canon Promotion Checklist
Status: Candidate
Date: 2026-05-26

Use this checklist when promoting a candidate artifact to canon.
Promotion should be deliberate, evidence-backed, and fully recorded.

## Promotion packet

- [ ] Artifact title, path, and artifact ID recorded
- [ ] Current status confirmed as `Candidate`
- [ ] Domain steward identified
- [ ] Version string assigned or confirmed
- [ ] `created`, `updated`, and status metadata complete

## Content readiness

- [ ] Scope is explicit and stable
- [ ] Internal contradictions resolved or documented
- [ ] Definitions and terminology are aligned with current doctrine
- [ ] Links resolve to existing repository artifacts
- [ ] Supersession and lineage fields are correct

## Evidence and provenance

- [ ] High-impact claims have traceable sources
- [ ] Citations are legible and reviewable
- [ ] Any external review notes are attached or linked
- [ ] Open questions are recorded with disposition

## Quality controls

- [ ] Metadata block conforms to [METADATA_SCHEMA.md](./METADATA_SCHEMA.md)
- [ ] Status header note is visible at the top of the file
- [ ] Link integrity check completed
- [ ] Domain scorecard impact reviewed
- [ ] Website publication suitability assessed if public amplification is expected

## Governance approvals

- [ ] Domain steward recommends promotion
- [ ] Council review completed
- [ ] Vote record captured in decision log format
- [ ] Final adjudication by @atlaslattice captured

## Publication actions

- [ ] Canon decision log entry created
- [ ] Any superseded artifact updated to archived or deprecated state as appropriate
- [ ] Relevant indexes, maps, and changelog streams updated
- [ ] Public website gate checked if the artifact is website-bound

## Closeout

- [ ] Promotion date recorded as the actual decision date in `YYYY-MM-DD` format
- [ ] Review cadence scheduled for next audit window
- [ ] Steward confirms no blocking issues remain

## Notes

If any box remains unchecked, the artifact should remain Candidate unless an exception is explicitly recorded in the canon decision log.
