# Public Excellence Playbook

## Purpose

This playbook defines how repository improvements are executed to achieve and maintain world-class public quality.

## Execution Loop

1. Select tasks from the [Aetherforge 144-Task Campaign](../projects/aetherforge-144-task-campaign-2026-05-27.md).
2. Implement in small, reviewable changes.
3. Validate locally and in CI.
4. Record receipts in project boards.
5. Update guidance docs and repeat.

## Standard of Completion

A change is considered complete only when it is:

- merged,
- validated by relevant checks,
- linked from the active board as a receipt,
- consistent with canon-boundary policy.

## Quality Pillars

- **Documentation:** navigable, concise, linked, and consistently formatted.
- **Governance:** clear candidate/canon boundaries with explicit ratification references.
- **Security:** no secrets, dependency and workflow risk controls enabled.
- **Automation:** checks for links, structure, and reliability.
- **Contributor UX:** strong templates, clear onboarding, predictable review flow.

## Annual Reassessment Inputs

- Link integrity trends.
- Contributor throughput and review time.
- Coverage and reliability of quality gates.
- Artifact provenance and citation quality.
- Public discoverability and onboarding success.
