## Five-Step Starter Path

1. Read [CONTRIBUTING.md](../../.github/CONTRIBUTING.md) to understand candidate/canon boundaries.
2. Use the [Contributor Decision Tree](../contributor-decision-tree.md) to pick the right kind of change.
3. Choose a first task from the [Aetherforge questboard](../aetherforge/questboard-2026-05-28.md).
4. Open the relevant [issue template](../../.github/ISSUE_TEMPLATE/) or draft a PR using the repo template.
5. Run the existing validation checks for your change and include the outcome in your PR.
