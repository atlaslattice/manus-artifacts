# Comparison Repositories — 2026-05-28

> *Status: CANDIDATE — not canon until ratified by @atlaslattice*

## What This Document Is

This comparison set identifies public repositories that demonstrate qualities Atlas Lattice can study and adapt. The goal is not imitation; it is extracting patterns for public clarity, contributor trust, documentation depth, and durable discoverability.

## Comparison Set

| Repository | What we can learn | What they do well | How Atlas Lattice compares |
|---|---|---|---|
| [`kubernetes/kubernetes`](https://github.com/kubernetes/kubernetes) | Large-scale public architecture, contributor routing, and governance at ecosystem scale. | Excellent governance surface, contributor docs, SIG structure, and operational maturity. | Atlas Lattice is far smaller and more narrative-driven; it needs clearer ownership and process legibility to approach this standard. |
| [`facebook/react`](https://github.com/facebook/react) | Tight public documentation around a high-impact technical core. | Clear README, stable docs, disciplined issue/PR flow, and strong ecosystem discoverability. | Atlas Lattice has a richer mission narrative but less concise technical onboarding. |
| [`google/guava`](https://github.com/google/guava) | API-oriented public presentation and disciplined maintenance posture. | Clean scope, predictable documentation, and strong trust signals for a long-lived library. | Atlas Lattice is broader and less bounded; it needs stronger scoping cues at the domain level. |
| [`microsoft/vscode`](https://github.com/microsoft/vscode) | World-class repository navigation for a massive, actively developed product. | Excellent contributor experience, issue templates, governance signals, and docs ecosystem. | Atlas Lattice has promising narrative architecture but still lacks comparable operational polish and contributor scaffolding. |
| [`sindresorhus/awesome`](https://github.com/sindresorhus/awesome) | Discoverability, curation clarity, and simple public navigation. | Obvious value proposition, readable structure, and effortless skimmability. | Atlas Lattice has more depth and complexity, but it can borrow this project's ruthless clarity and entry-point simplicity. |
| [`huggingface/transformers`](https://github.com/huggingface/transformers) | AI-adjacent documentation scale, model discoverability, and public trust-building. | Rich docs, strong examples, high discoverability, and visible maintenance maturity. | Atlas Lattice has stronger governance language than most AI repos, but much lighter examples, tutorials, and production evidence. |
| [`EleutherAI/lm-evaluation-harness`](https://github.com/EleutherAI/lm-evaluation-harness) | Evaluation rigor, benchmark framing, and methodology legibility. | Clear benchmarking purpose, reproducible evaluation patterns, and practical researcher value. | Atlas Lattice can learn from its methodological directness and clearer evidence pathways. |

## Synthesis

The strongest shared lesson across these repositories is not just “more docs.” It is disciplined public interfaces: obvious entry points, explicit ownership, reproducible checks, and documentation that reduces cognitive load instead of amplifying mystique. Atlas Lattice already has unusual mission clarity and governance ambition; the next leap is making those strengths legible at first contact.
