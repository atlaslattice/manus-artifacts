# Launch Threshold — 2026-05-28

> *Status: CANDIDATE — not canon until ratified by @atlaslattice*

## What This Document Is

This document defines the minimum public-quality threshold Atlas Lattice should meet before a major public launch push. The threshold is intentionally stricter than “good enough” because the repository makes ambitious claims about governance, provenance, and constitutional AI systems.

## Minimum Launch Threshold

- **Required benchmark score:** **30 / 40 (75%)**
- **Current benchmark score:** **25 / 40 (62.5%)**
- **Gap to threshold:** **5 points**

## Non-Negotiable Requirements

- A documented **safety audit** exists for any system-facing claims that imply execution, autonomy, or governance authority.
- The **canon boundary** is explicit everywhere: candidate artifacts must never be mistaken for ratified authority.
- There is **no exposed PII** or other sensitive personal material that should not be publicly surfaced.
- Core navigation paths are stable enough that a first-time reader can orient without private context.
- CI and validation checks are green for the repository's public trust surface.

## Nice-to-Have Improvements

- Additional badges and trust signals on the root README.
- More architecture diagrams and visual maps.
- More topic pages and persona-specific reading guides.
- Higher artifact-registry coverage and evidence-ledger density.
- CODEOWNERS and clearer review routing for future contributors.

## Current Status vs Threshold

| Area | Threshold posture | Current status |
|---|---|---|
| Score | 30/40 minimum | 25/40 — below threshold |
| Safety | Auditable and explicit | Improving, but not yet comprehensive |
| Canon boundary | Unmistakable | Strong at repo level, uneven in deeper domains |
| Sensitive data exposure | None | Must remain continuously reviewed |
| Discoverability | Strong newcomer path | Better than before, still inconsistent across domains |

## Recommendation

Atlas Lattice should treat the current state as **promising but pre-launch**. A public push is reasonable only after the remaining 5-point gap is closed, the non-negotiables are verified, and the evidence/knowledge-graph layers become materially denser.
