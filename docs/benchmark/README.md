# Benchmark

> *Status: CANDIDATE — not canon until ratified by @atlaslattice*

## What This Folder Is

The `docs/benchmark/` folder collects public-quality benchmarking artifacts for Atlas Lattice. It defines what “world class” means for an open repository, compares the archive to strong public examples, scores the current state, and sets a minimum launch threshold before broader public amplification.
