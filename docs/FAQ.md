# Documentation FAQ

> **Status:** Candidate
> **Last reviewed:** 2026-05-28
> **Provenance:** Maintained in GitHub as a recurring-questions reference for repository contributors.

## What is this repository for?

This repository is the public Atlas Lattice knowledge archive for governance, AI systems,
research artifacts, and execution boards.

## What is canon vs candidate?

Candidate means proposed and not yet ratified. Canon requires full council ratification and
adjudication by @atlaslattice.
