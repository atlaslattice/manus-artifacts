1. **Find broken or missing links** — inspect README hubs, topic pages, and target artifacts for dead ends.
2. **Trace the target artifact** — confirm the correct destination path, stable ID, or conceptually nearest artifact.
3. **Update the source artifact** — add direct links, related-doc sections, or clearer traversal notes.
4. **Update the registry when needed** — if the relationship is trust-relevant or long-lived, queue a registry relation update.
5. **Validate the path** — confirm the links resolve and the navigation path makes sense for a new reader.
6. **Emit a receipt** — record what links were added or repaired and any remaining gaps.
