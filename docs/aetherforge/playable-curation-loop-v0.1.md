A complete archive work session can be treated as an Aetherforge play session: enter with a quest, perform the curation action, validate the result, then bank the XP and receipt.

## Pre-Session

1. Boot **TIDELOCK** and review current repository state.
2. Open the [questboard](./questboard-2026-05-28.md).
3. Pick one quest with explicit acceptance criteria.

## Main Loop

1. Execute the quest against the target artifact.
2. Run the relevant existing validator or test suite.
3. Emit a receipt with links to the changed artifact and validation outcome.
4. Log the result in TIDELOCKBrain or the session receipt surface.

## Post-Session

1. Update quest status or blockers on the questboard.
2. Queue any follow-on quest generated by the change.
3. Take a short rest / REM break before the next session.

## Sample Play Log

| Phase | Action | Result |
| --- | --- | --- |
| Boot | Checked archive health and questboard. | Selected `QST-001` because metadata coverage is still below target. |
| Quest | Added missing provenance to a flagship document. | Artifact moved from implicit to explicit candidate state. |
| Validation | Ran metadata completeness and graph-adjacent checks. | Receipt recorded pass status and one follow-up gap. |
| Log | Added session note to TIDELOCK receipt surface. | Quest closed or carried forward with a blocker note. |
| Recovery | Took a rest / REM break. | Session ended with next quest identified. |
