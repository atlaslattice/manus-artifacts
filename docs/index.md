# Atlas Lattice

> *"The intent is to make all of my work public and open source and world class."*  
> — David Sheldon (@atlaslattice)

**Atlas Lattice** is a provenance-first knowledge-graph archive organized by the **H-S-N coordinate system** — a 12×12×12 hypercube addressing 1,728 cells across Houses, Spheres, and Nodes.

## Quick Start

```bash
pip install atlas-lattice
python -m atlas_lattice lookup H04-S09-N02
```
