# Public Repository North Star

## Mission

Build and maintain a public, open-source, world-class knowledge archive that is easy to navigate, easy to verify, and safe for broad contribution.

## Outcomes

1. **Clarity:** New contributors can understand the repository in under 30 minutes.
2. **Trust:** Every major claim is traceable to sources and provenance receipts.
3. **Durability:** Artifacts remain discoverable, link-stable, and versioned over time.
4. **Safety:** Security, dependency, and workflow hygiene checks run continuously.
5. **Velocity:** Contributors can propose, review, and merge high-quality work quickly.

## Public Quality Principles

- **Provenance first:** Claims without sources are candidates, not canon.
- **Governance first:** Canon status requires council ratification and adjudication by @atlaslattice.
- **Automation first:** Repeatable quality checks should be encoded in CI.
- **Navigation first:** Users should always have clear paths to related context.
- **Transparency first:** Decisions, changes, and tradeoffs should be visible in the repository.
