## How to add an entry

1. Open a PR introducing the artifact with `canon_status: CAND` in frontmatter.
2. Add a row here with `Review status: awaiting council`.
3. Update to `ratification_pending` once council review is complete.
4. Remove from this registry and add to the Canon Registry upon ratification.
