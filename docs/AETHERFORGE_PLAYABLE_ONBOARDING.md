# Aetherforge Playable Onboarding

## Start Path

1. Read `docs/START_HERE.md`.
2. Open `projects/aetherforge-next144-taskboard-2026-05-28.md`.
3. Pick one task in `Ready` lane.
4. Validate dependencies and gate requirements.
5. Complete task with evidence, then move to `Done`.

## Progression Loop

- Quest selection
- Implementation
- Quality-gate validation
- Evidence publication
- Board state update

## Role Lanes

- Curator: metadata + provenance cleanup
- Mapper: graph links and architecture crosswalks
- Verifier: tests, CI, and quality-gate calibration
- Storykeeper: release logs, evidence snapshots, trust reporting
