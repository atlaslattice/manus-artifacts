# Aetherforge / GPTBrain Glossary

Status: candidate glossary (not canon)

- **Aetherforge**: umbrella execution program for public-readiness, governance hardening, and world-class repository quality.
- **Canon**: artifact state granted only after explicit adjudication and ratification workflow.
- **Candidate**: committed artifact pending canon adjudication.
- **Council**: governance body for review and decision-making; human authority remains with @atlaslattice.
- **Drive/Notion Relay Layer**: non-authoritative working vaults; not canonical merge authority.
- **GitHub Canonical Substrate**: durable source of truth for review trail, receipts, and ratified artifacts.
- **KG (Knowledge Graph)**: connected entity-relation substrate spanning artifacts, claims, and provenance.
- **Metatron Frame**: repository planning style using structured rings/waves for execution.
- **Play/REM/Work (8/8/8)**: operational cadence model balancing execution, restoration, and synthesis.
- **Provenance**: traceable source and transformation lineage for a claim or artifact.
- **Receipt**: evidence binding from claim to source, reviewer, and trust state.
- **TIDELOCKBrain**: logging and synthesis lane for implementation work artifacts.
- **Top-10 / Top-50 / 144 Board**: sprint, portfolio, and program-level execution hierarchy.
- **Trust State**: confidence/governance status attached to artifacts or claims.
