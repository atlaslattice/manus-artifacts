The intake system defines how Atlas Lattice moves artifacts from working vaults such as Notion and Drive into durable GitHub archive paths without losing provenance.

## Intake Goals

1. Preserve original authorship and source context.
2. Normalize imported artifacts into repo conventions.
3. Emit a receipt for every migration.
4. Hold registry admission behind validation.
