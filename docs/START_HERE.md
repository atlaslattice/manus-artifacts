## 🧭 What Is This?

This repository is an **open knowledge archive** — a living record of systems
thinking, constitutional AI design, and world-building at the frontier of
human-machine collaboration.

It is organized around several major domains:

| Domain | What you'll find |
|---|---|
| **Aluminum OS** | Constitutional substrate for regenerative computing |
| **GPTBrain / Aetherforge** | Agent architecture, swarm protocols, dream cycles |
| **SheldonBrain** | System architecture and knowledge substrate |
| **BAZINGA** | Constitutional middleware and launch protocols |
| **Council** | Governance sessions, ratification archives, policy |
| **Projects** | Free Bank, Chinook Guardian, Three-Tier Autonomy |
| **Research** | Intelligence sweeps, convergence reports, tech analysis |
| **Health** | Patient rights and regenerative wellness research |
