# Atlas Lattice Contributor Playbook

## 1) Governance and Canon Rules

- GitHub is the durable source-of-truth substrate.
- Artifacts are candidates unless explicitly ratified.
- Canon promotion requires ratification receipt and adjudication state.
- Governance changes must leave a documented evidence trail.

## 2) Standard Contributor Workflow

1. Pick task from active board/issue queue.
2. Confirm dependencies and status lane (`Ready`, `In Progress`, `Done`).
3. Make smallest complete change set.
4. Run required validation commands.
5. Publish evidence in changed artifacts.
6. Update board and checkpoint links.

## 3) Quality Gates

- Metadata and provenance checks must pass.
- Lattice quality-gate checks must pass.
- Relevant test suites must pass for touched protocol surfaces.
- Documentation changes must maintain valid links and references.

## 4) Required Evidence on Completion

- What changed
- Why it changed
- Validation evidence
- Remaining risks/blockers
- Next dependent action
