## Core idea

The Lattice Hypercube is a candidate 12×12×12 coordinate system for organizing knowledge, matter, resonance, artifacts, and review state.

It is intended as a Periodic Table 2.0 ambition, not a completed scientific standard.

It maps candidate relationships among:

- known human knowledge
- matter and material properties
- elements and isotopes
- states of matter
- frequency ranges
- acoustic resonance
- color and harmonic spectrum
- neuromorphic principles
- user-authored archive artifacts
- evidence logs for AI systems built or coordinated by the user

## Shape

```text
12 × 12 × 12 = 1,728 coordinate cells
```

Candidate coordinate form:

```text
A##.B##.C##
```

Where:

- A-axis = matter / substrate / physical property lane
- B-axis = frequency / resonance / harmonic lane
- C-axis = knowledge / artifact / review-state lane

### A-axis — Matter / Substrate / Physical Property Lane

The A-axis indexes the physical, material, and substrate domain of a node. It answers: *what physical thing or property class does this relate to?*

| Code | Category | Representative scope |
|------|----------|----------------------|
| A01 | Elements & Isotopes | Confirmed and theoretical elements (Z=1–144+); isotope families; nuclear properties |
| A02 | States of Matter | Solid, liquid, gas, plasma, Bose-Einstein condensate, photonic, exotic states |
| A03 | Crystal & Structural Geometry | Space groups, coordination numbers, lattice parameters, symmetry classes, topology |
| A04 | Electronic & Quantum Properties | Band gap, effective mass, spin-orbit coupling, topological index, Berry phase |
| A05 | Magnetic & Spin Properties | Magnetic moment, exchange coupling, Curie temperature, spin polarization, chirality |
| A06 | Thermal & Phonon Properties | Thermal conductivity, Debye temperature, phonon dispersion, heat capacity |
| A07 | Mechanical & Elastic Properties | Mass density, hardness, bulk modulus, compressibility, fracture toughness |
| A08 | Optical & Electromagnetic Properties | Dielectric function, optical conductivity, plasmon resonance, refractive index |
| A09 | Synthesis & Fabrication | Synthesis route, stability window, precursor availability, scalability indicator |
| A10 | Defect & Imperfection Behavior | Vacancy formation energy, defect migration barrier, doping response, grain boundary |
| A11 | Neuromorphic & Biological Substrate | Membrane properties, ion channel behavior, synaptic weight analog, bio-material interface |
| A12 | Meta-substrate / Coordination Layer | Cross-material relations, composite properties, emergent substrate behavior, Element 145 analogue |

A-axis rule:

```text
A-axis assignment describes a physical or material domain.
It is not a scientific proof.
It is not a deployment claim.
Physical proximity in A-axis space is a suggestion for review, not equivalence.
```

The B-axis indexes the resonance, frequency, wave, and harmonic domain of a node. It answers: *what oscillation, wave, or energy-transfer class does this relate to?*

| Code | Category | Representative scope |
|------|----------|----------------------|
| B01 | Acoustic / Mechanical Waves | Sound speed, phonon modes, acoustic resonance, vibration spectra, Schumann resonance |
| B02 | Radio & Microwave Frequencies | RF band, microwave, radar, antenna resonance, GHz range |
| B03 | Infrared & Thermal Radiation | IR absorption, thermal emission, blackbody peaks, heat signature |
| B04 | Visible Light & Color Spectrum | ROYGBIV, photon wavelength 380–700 nm, color harmonics, optical cavity |
| B05 | Ultraviolet & Ionizing Radiation | UV, X-ray, gamma, ionization threshold, photoelectric effect |
| B06 | Quantum & Particle Frequencies | De Broglie wavelength, zero-point energy, Planck-scale oscillation |
| B07 | Spin & Magnetic Resonance | NMR, EPR, Larmor frequency, spin precession, magnetic field resonance |
| B08 | Plasma & Electromagnetic Oscillation | Plasma frequency, cyclotron resonance, Alfvén wave, magnetohydrodynamics |
| B09 | Biological & Neural Frequencies | Brainwave bands (delta/theta/alpha/beta/gamma), heartbeat, circadian rhythms |
| B10 | Riemann Spectral / Critical Strip | Zeta zero spacing, spectral statistics of Hamiltonians, GUE universality signal |
| B11 | Color Harmonic & Synesthetic Map | Cross-modal frequency-to-color-to-sound mapping; Rainbow Yin Yang spectrum overlay |
| B12 | Chiral Dissonance / Anomaly Signal | Resonance mismatch, typed conservation failure, chiral asymmetry signal |

B-axis rule:

```text
B-axis assignment describes a resonance or frequency domain.
Frequency proximity is a candidate suggestion, not physical equivalence.
Riemann spectral entries (B10) carry no mathematical proof.
Color and synesthetic entries (B11) are metaphor/design layer only.
```

### C-axis — Knowledge / Artifact / Review-State Lane

The C-axis indexes the knowledge, artifact type, and review-state of a node. It answers: *what kind of artifact or knowledge object is this, and what is its review state?*

| Code | Category | Representative scope |
|------|----------|----------------------|
| C01 | Raw Source Material | Uploaded text, unprocessed data, ingested feed, raw observation |
| C02 | Source Record & Provenance | Parsed source, lineage entry, D0 provenance packet, hash receipt |
| C03 | Claim Ledger Entry | Candidate claim, assertion, hypothesis, pending verification |
| C04 | Artifact Registry Entry | Named artifact, catalog record, schema-validated envelope |
| C05 | Candidate Plan / Synthesis | Draft plan, candidate document, synthesis under active review |
| C06 | Execution Diff / Preview | Change set, proposed mutation, execution preview awaiting gate |
| C07 | Verifier / Audit Packet | Review output, audit trail, verifier assessment, QA record |
| C08 | Contradiction Record | Logged conflict, open contradiction, unresolved mismatch |
| C09 | Quarantine / Blocked | Flagged material, blocked artifact, sensitivity-routed item |
| C10 | Advisory / Recommendation | Non-authoritative suggestion, design guidance, candidate recommendation |
| C11 | Canon Candidate Packet | Ratification-nominated artifact, council review pending, staged for promotion |
| C12 | Canon / Governance Authority State | Ratified artifact only; requires explicit ratification_event_id + human-root sign-off |

C-axis rule:

```text
C-axis assignment describes knowledge type and review state.
C12 is unreachable without explicit ratification.
Nothing self-promotes to C12 by being well-written, frequently cited, or model-endorsed.
```
