# Newcomer Guide
Status: Candidate
Date: 2026-05-26

This guide is the fastest high-signal path into the Manus archive for a first-time reader.
It assumes no insider context and prioritizes orientation before depth.

## First rule

Start by understanding authority.
Everything in the repository is a candidate unless and until it is ratified by the full council and adjudicated by @atlaslattice.

If you only have five minutes, read these in order:

## Suggested mental model

Think of the repository as an archive program, not a product brochure.
Some artifacts explain doctrine, some document projects, and some define the rules by which authority is granted.
Aetherforge is the current improvement gameboard for making all of that world-class.
