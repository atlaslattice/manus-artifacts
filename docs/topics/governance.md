## Canon Policy

Atlas Lattice governance keeps artifacts public and candidate by default while reserving canon promotion for explicit review and human-root adjudication.

## Ratification Flow

1. Candidate artifact is authored and published.
2. Council review evaluates contradictions and evidence.
3. Human-root adjudication assigns trust state.
4. Canon promotion happens only when ratification metadata is complete.

## Trust States

The core trust boundary is documented through candidate, ratified, archived, and deprecated lifecycle states, with supporting evidence carried by receipts and schemas.
