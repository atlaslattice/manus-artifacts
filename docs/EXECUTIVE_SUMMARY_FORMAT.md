# Executive Summary Format
Status: Candidate
Date: 2026-05-28

One-pager standard format for flagship artifacts.

## Required blocks

1. **Title**
2. **TL;DR** (2-4 sentences)
3. **Key claims** (3-5 numbered claims)
4. **Current status** (Candidate / Under Review / Ratified)
5. **Primary risks**
6. **Evidence + validation receipts**
7. **Next actions**

## Governance guardrails

- Claims must include provenance links.
- Canon language must follow candidate-first governance.
- Any high-impact claim must include validation timestamp.
