# Archive Taxonomy (Candidate)

This taxonomy normalizes archive structure for consistent navigation and stewardship.

## Domain categories

1. **Systems**  
   Core technical systems, doctrine engines, and substrate architecture.  
   Primary paths: `aluminum-os/`, `sheldonbrain/`, `bazinga/`

2. **Projects**  
   Program execution boards and applied initiatives.  
   Primary path: `projects/`

3. **Governance**  
   Council process, review logs, and adjudication surfaces.  
   Primary paths: `council/`, `council-reviews/`

4. **Research**  
   Intelligence, synthesis, and exploratory artifacts.  
   Primary path: `research/`

5. **Health**  
   Health, patient rights, and wellness research artifacts.  
   Primary path: `health/`

6. **Vault**  
   Internal continuity, session memory, and checkpoint archives.  
   Primary paths: `manus-vault/`, `archives/janus-checkpoints/`

## Usage rules

- New artifacts should be filed under one primary domain.
- Cross-domain links are encouraged, but ownership should remain explicit.
- Domain naming in docs should use the six labels above for consistency.
