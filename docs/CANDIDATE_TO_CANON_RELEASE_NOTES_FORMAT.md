# Candidate to Canon Release Notes Format
Status: Candidate
Date: 2026-05-28

Use this format when publishing release notes for a `Candidate -> Canon` lifecycle change.

## Required fields

1. Decision ID
2. Artifact path and title
3. Lifecycle transition statement
4. Effective date
5. Version identifier
6. Council vote summary
7. Adjudication statement
8. Evidence summary
9. Supersession/lineage impact
10. Public communication links

## Canon release notes template

```text
Decision ID:
Date:
Artifact:
Lifecycle change: Candidate -> Canon
Version:

Summary:

Council vote:

Adjudication:

Evidence reviewed:
- 

Supersession notes:

Publication actions:
- 
```

## Publishing checklist

- Include links to the decision record and promotion checklist packet.
- Confirm any superseded artifact has updated status and lineage metadata.
- Link release notes from governance and roadmap/public reporting surfaces.
