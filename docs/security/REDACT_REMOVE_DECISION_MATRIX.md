# Redact/Remove Decision Matrix

Status: candidate policy aid (not canon)

| Condition | Action | Notes |
|---|---|---|
| Confirmed live secret/API key | Redact + rotate/revoke + consider history rewrite | Prioritize immediate risk containment |
| Sensitive personal data (regulated) | Redact + legal/privacy review + possible rewrite | Preserve non-sensitive audit context |
| Public reference contact info | Keep with provenance | No removal required |
| Historical governance statement with sensitive token-like value | Redact inline + preserve record note | Avoid silent deletion |
| False positive scanner finding | Document as false positive | Keep evidence trail |
