# Canonical Source-of-Truth Policy

## Policy Statement

Within this repository, all artifacts are treated as **candidates** unless they are explicitly ratified by council process and adjudicated by @atlaslattice.

## Canon Boundary Rules

1. **Default state:** Candidate.
2. **Promotion requirement:** Explicit ratification event and adjudication.
3. **No implied canon:** Presence in repository does not imply canonical status.
4. **Traceability required:** Promotion decisions must include provenance and rationale.

## Source-of-Truth Layers

- **Repository layer:** Durable working substrate for artifacts, code, and receipts.
- **Governance layer:** Council review and adjudication records.
- **Public surface layer:** External publication surfaces can only be treated as canon when explicitly ratified.

## Required Metadata for Canon Promotion

- Artifact identifier and location.
- Ratification event reference.
- Canon status declaration.
- Trust/provenance references.
