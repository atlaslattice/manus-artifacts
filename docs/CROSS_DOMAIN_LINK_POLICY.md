# Cross-Domain Link Policy (v0.1)

> **Status:** Candidate  
> **Purpose:** Keep links stable, public-safe, and knowledge-graph compatible.

## Rules

1. Use repository-relative links for internal references.
2. Prefer linking to canonical navigation surfaces for each domain:
   - Docs: `docs/ARCHIVE_INDEX.md`
   - Gameplay/workboards: `projects/aetherforge-metatrons-cube-top50-taskboard-2026-05-26.md`
   - GPTDream++ protocols: `archive/boot/gptbrain/REM8_DREAM_PROTOCOL.md`
3. Add explicit status labels (`Candidate`, `Active`, `Archived`) where ambiguity could cause authority drift.
4. Do not imply canon authority from cross-links alone.
5. When linking dream/play artifacts, include non-execution boundaries.

## Domain bridge checklist

- [ ] Link resolves locally
- [ ] Link target has visible status
- [ ] Target is appropriate for public readers
- [ ] Canon boundary language remains intact
- [ ] Relationship intent is clear (index, route, derive, validate)
