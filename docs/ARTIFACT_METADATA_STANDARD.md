# Artifact Metadata Standard

```
STATUS: CANDIDATE — not canon
PURPOSE: Universal metadata field definitions for all artifacts in the Lattice KG.
         Addresses Axis 04 tasks 37-43 from the 144-task campaign.
OWNER: @atlaslattice
UPDATED: 2026-05-28
```

---

## Why This Standard Exists

For the knowledge graph to be machine-retrievable and synthesis-ready, every
artifact needs a consistent, queryable metadata header. This document defines
the universal schema so that:

1. Any agent can parse and index any artifact
2. Source provenance is unambiguous (GitHub, Notion, Drive, chatlog)
3. Canon trust state is machine-readable
4. Cross-repo synthesis can resolve duplicates and contradictions

---

## Metadata Fields (v0.1)

### Required Fields

| Field | Type | Allowed Values | Description |
|---|---|---|---|
| `STATUS` | string | `CANDIDATE`, `CANON`, `DEPRECATED`, `QUARANTINE` | Lifecycle state (see CANON_LIFECYCLE_STATE_MACHINE.md) |
| `source_system` | string | See Source System Vocabulary below | Original source of this artifact |

### Recommended Fields

| Field | Type | Example | Description |
|---|---|---|---|
| `artifact_id` | string | `ART-2026-05-28-001` | Unique stable ID (format: `ART-YYYY-MM-DD-NNN`) |
| `created` | ISO 8601 date | `2026-05-28` | Date artifact was first created |
| `updated` | ISO 8601 date | `2026-05-28` | Date artifact was last modified |
| `author` | string | `@atlaslattice`, `manus-agent`, `gptbrain-s1` | Human or agent who produced this |
| `domain` | string | See Domain Vocabulary below | Thematic classification |
| `tags` | comma-separated | `aluminum-os, governance, spec` | Free-text ontology tags |
| `ratification_event_id` | string | `RAT-2026-05-28-001` | Canon ratification event (required for CANON status) |
| `canon_status` | string | `pre-candidate`, `candidate`, `ratified`, `superseded` | Fine-grained canon state |
| `trust_state` | string | `unreviewed`, `council-reviewed`, `human-root-approved` | Trust chain state |
| `confidence_score` | float 0.0–1.0 | `0.85` | Evidence confidence (0 = none, 1 = fully verified) |
| `related_artifacts` | list | `ART-2026-05-08-001, ART-2026-05-09-002` | Cross-links to related artifacts |
| `lineage_depth` | int | `2` | Generations removed from primary source (0 = primary) |
| `summary` | string | 1–3 sentences | Retrieval-optimized plain-language summary |

### Provenance Fields (for ingested external content)

| Field | Type | Example | Description |
|---|---|---|---|
| `source_url` | URL | `https://github.com/atlaslattice/uws/blob/main/README.md` | Original URL |
| `source_hash` | string | `sha256:abc123...` | Hash of source at time of ingestion |
| `ingested_at` | ISO 8601 date | `2026-05-28` | When this was ingested into manus-artifacts |
| `transformation` | string | `verbatim`, `summarized`, `normalized` | How source was transformed |

---

## Header Block Format

Artifacts should declare metadata in a fenced code block near the top of the
file (within the first 60 lines, so the index scanner can find them):

```
STATUS: CANDIDATE
source_system: github:aluminum-os
artifact_id: ART-2026-05-28-001
created: 2026-05-08
author: @atlaslattice
domain: aluminum-os
tags: architecture, spec, governance
confidence_score: 0.75
summary: Defines the Aluminum OS unified architecture specification including kernel, plugin, and substrate layers.
```

## Source System Vocabulary

pipeline (`scripts/build_lattice_global_index.py`):

| `github:manus-artifacts` | Originated in this repository |
| `github:aluminum-os` | From atlaslattice/aluminum-os |
| `github:uws` | From atlaslattice/uws |
| `github:sheldonbrain-rag-api` | From atlaslattice/sheldonbrain-rag-api |
| `github:sheldonbrain` | From sheldonbrain-omega-v1 (internal) |
| `github:snrs` | From atlaslattice/snrs |
| `github:atlas-lattice-foundation` | From atlaslattice/atlas-lattice-foundation |
| `github:element-145` | From atlaslattice/element-145 |
| `github:free-bank` | From atlaslattice/free-bank |
| `notion-export` | Exported from Notion workspace |
| `drive-export` | Exported from Google Drive |
| `manus-agent` | Generated by Manus AI agent session |
| `gptbrain-agent` | Generated by GPTBrain swarm agent |
| `research-sweep` | From an intelligence/research sweep |
| `chatlog-export` | From a raw chat log export |
| `human-authored` | Written directly by @atlaslattice |

To add a new source system: update `SOURCE_SYSTEM_HINTS` in
`scripts/build_lattice_global_index.py` and add an entry to this table.
