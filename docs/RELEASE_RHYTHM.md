# Recurring Release Rhythm

## Cadence

- Weekly: taskboard checkpoint + blocker review
- Monthly: quality/evidence/status report publication
- Quarterly: trust and readiness packet publication

## Required Artifacts Per Release Cycle

- changelog entry
- release notes
- milestone closeout checklist
- next-wave kickoff checklist

## Standard Checklist

1. Confirm completed tasks and validation evidence.
2. Publish changelog and release notes.
3. Publish blocker and risk delta summary.
4. Close milestone with canonical links.
5. Open next-wave kickoff artifact and issue batch.
