# Mission and Vision

Status: candidate strategy document (not canon)

## Mission

Build and maintain a fully public, provenance-first knowledge graph where every
artifact is traceable, reviewable, and linked for reliable human + agent use.

## Vision

Deliver a world-class open-source substrate that combines:

1. A functional knowledge graph lattice for retrieval and governance.
2. Aetherforge as a playable archival execution system.
3. GPTDream++ protocols as a transparent public research gift.

## Outcome Targets

- Publish high-quality, citation-backed archival artifacts at scale.
- Keep canon boundaries explicit: candidate first, ratified only by council flow.
- Improve machine readability and validation with automated quality gates.
- Enable contributors to onboard quickly and ship safely with clear governance.

## Non-Negotiable Constraints

- No artifact is canon until full council ratification and adjudication by
  @atlaslattice.
- GitHub is the canonical substrate for durable publication and review history.
- Unknowns must remain explicit; no overclaiming or unverifiable certainty.

## Execution Posture

- Treat project boards as source-of-truth execution layers.
- Track governance/security hardening with auditable markdown artifacts.
- Keep settings-only actions separate with explicit owner click-paths.
