# How to Play Aetherforge

```text
STATUS: CANDIDATE GUIDE — NOT CANON
```

Aetherforge frames repository execution as playable quests with strict validation and governance receipts.

## 1) Choose a quest lane

Pick one lane:
- Knowledge Graph connectivity
- Trust / provenance hardening
- Packaging / public release quality

## 2) Create a quest card

Use:
- `./templates/FUN_FRAMING_SERIOUS_ACCEPTANCE_TEMPLATE_v0.1.md`
- `./templates/QUEST_CARD_SCHEMA_v0.1.yaml`

Minimum fields:
- win conditions
- boss fight (adversarial test)
- receipts
- delta summary

## 3) Run the boss fight

Every quest must include evidence from checks/tests before merge.

## 4) Claim loot

Loot is a merged, reviewable artifact with lineage links and validation receipts.

## 5) Preserve canon boundaries

Nothing is canon without explicit ratification.
Candidate artifacts remain candidate until adjudicated.
