# Aetherforge Public Questboard v0.1
Status: Candidate
Date: 2026-05-27

This board turns archive maintenance into a playable public contribution layer with explicit receipts.

## Mission

Operate the archive as a game with serious outcomes:

- strengthen the functional lattice knowledge graph
- improve public readability and contribution flow
- keep GPTDream++ protocol work open and verifiable

## How quests are scored

- **+1** quest completion with artifact link
- **+1** validation receipt attached
- **+1** cross-domain relationship explicitly documented
- **+1** governance/quality linkage added

## Active quests

1. [ ] Add one high-signal node to [Lattice Knowledge Graph Node Index](../docs/LATTICE_KNOWLEDGE_GRAPH_NODE_INDEX.md)
2. [ ] Add one valid cross-domain link under [Cross-Domain Link Policy](../docs/CROSS_DOMAIN_LINK_POLICY.md)
3. [ ] Improve one map edge in [Public Archive Map](../docs/PUBLIC_ARCHIVE_MAP.md)
4. [ ] Add one GPTDream++ surface clarification in [archive/spec/gptdream/README.md](../archive/spec/gptdream/README.md)
5. [ ] Attach one validation receipt from [Validation Playbook](../docs/VALIDATION_PLAYBOOK.md)
6. [ ] Publish one weekly digest from [Weekly Delta Digest Template](../docs/WEEKLY_DELTA_DIGEST_TEMPLATE.md)
7. [ ] Submit one board update to [Aetherforge Top 50](./aetherforge-metatrons-cube-top50-taskboard-2026-05-26.md)
8. [ ] Submit one governance-safe release note using [Quality Gates](../docs/QUALITY_GATES.md)
9. [ ] Add one test linkage in [tests/README.md](../tests/README.md)
10. [ ] Log one TIDELOCK work receipt in `archive/boot/gptbrain/agents/TIDELOCKBrain/`
