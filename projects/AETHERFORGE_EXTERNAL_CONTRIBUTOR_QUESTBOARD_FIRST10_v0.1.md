# Aetherforge External Contributor Questboard (First 10)
Status: Candidate
Date: 2026-05-28

External-first questboard for contributors who want clear, receipt-driven tasks.

## Contribution rules

- Keep changes scoped to one quest per pull request when possible.
- Include validation command output in your quest receipt.
- Preserve historical artifacts; deprecate with lineage notes instead of deleting.

## First 10 quests

1. [ ] Add one high-signal glossary improvement in `docs/GLOSSARY.md`.
2. [ ] Add one cross-domain relationship in `docs/PUBLIC_ARCHIVE_MAP.md`.
3. [ ] Improve one newcomer navigation path in `docs/NEWCOMER_GUIDE.md`.
4. [ ] Add one governance evidence link in `governance/PROVENANCE_REQUIREMENTS.md`.
5. [ ] Add one risk mitigation refinement in `governance/RISK_REGISTER.md`.
6. [ ] Expand one roadmap KPI note in `docs/PUBLIC_ROADMAP_KPI_SCOREBOARD.md`.
7. [ ] Add one validation-playbook command clarification in `docs/VALIDATION_PLAYBOOK.md`.
8. [ ] Add one doctrine map edge in `docs/DOCTRINE_MAP.md`.
9. [ ] Add one quest completion example in `projects/AETHERFORGE_PUBLIC_QUESTBOARD_v0.1.md`.
10. [ ] Add one mission-control reporting refinement in `governance/MISSION_CONTROL_CADENCE.md`.

## Quest receipt format

```text
Quest ID:
PR/Commit:
File(s) changed:
Validation command(s):
Result:
Date:
```
