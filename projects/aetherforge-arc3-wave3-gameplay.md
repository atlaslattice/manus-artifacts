## Arc Premise

The Lattice has grown. Hundreds of artifacts now exist in the archive, but many
float as **unconnected nodes** — present in the graph but unreachable from the
main spine. Arc 3 is the **Graph Weaver's Trial**: locate orphaned nodes, forge
missing edges, and strengthen the quality gates that protect the KG hypercube.

## Arc Stages

### Stage 1 — The Unmapped Territories (Wave 3 tasks 1-5)

*"Scan the lattice and expose the dark nodes."*

- Deploy graph-link integrity checker → exposes broken edges
- Deploy metadata validator → marks nodes with missing field coverage
- Generate global artifact index → snapshot of the full KG state
- Run markdown link audit → find dangling surface refs
- Run orphan detector → enumerate disconnected nodes

**Gameplay mechanic**: Each discovered orphan earns an **Edge Token**. Tokens
unlock Stage 2 forge actions.

### Stage 2 — Forging the Edges (Wave 3 tasks 6-9)

*"Use the Edge Tokens to connect the dark nodes to the spine."*

- Publish GPTDream cross-links → connect spec docs ↔ schemas ↔ ref impls
- Publish canon candidate register → connect candidates to governance flow
- Enhance onboarding journey → connect new contributors to their first Edge
- Build TIDELOCKBrain ARTIFACT_INDEX → connect all dream logs into one index

**Gameplay mechanic**: Each forged edge increments the **Lattice Coherence Score**.
Reaching 70% coherence unlocks Stage 3.

### Stage 3 — The Playable Arc (Wave 3 task 10)

*"The graph sings when enough edges are lit."*

Design and publish Arc 4 gameplay (the next 10-task wave) using the
cross-reference map as the game board. Every new task must reference at least
one existing artifact in the KG. No orphan task nodes allowed.

**Gameplay mechanic**: Final boss is the **Arc 4 Design Doc** — it must achieve
full Metatron's Cube structure (1 center + 12 surrounding in the Vesica Piscis).
