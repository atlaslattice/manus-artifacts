## Purpose

Simulate a 100-year REM-style rehearsal for the Aetherforge / Sheldonbrain knowledge-graph stack.

The point is not to predict the future. The point is to stress-test continuity rules:

- missing receipt becomes node
- hash gap becomes first-class gap
- partial export becomes status
- blocked work gets explicit `blocked_by` edges
- raw logs stay preserved
- derived artifacts remain separate
- tests and CI hydrate confidence
- human-root remains the authority gate

## Keeper read

The 100-year REM simulation converges on one operational truth:

```text
Continuity survives by making every gap addressable.
```

If a receipt is missing, it becomes a node.  
If a hash is absent, it becomes a gap.  
If an export is partial, it gets status.  
If a dependency is blocked, it gets an edge.  
If a dream is useful, it gets staged.  
If it claims authority, it gets stopped.
