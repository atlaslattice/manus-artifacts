# Contributing to the Aetherforge Simulation Sandbox

Thank you for improving the sandbox.

## Ground rules

This subtree is for practical local simulation infrastructure only.

- Keep changes reproducible.
- Keep runtime dependencies at zero unless review shows a clear need.
- Prefer synthetic fixtures over private or sensitive data.
- Keep examples small enough for a new contributor to run locally.
- Add tests when behavior changes.

## Good first tasks

Start with one task from `task-matrix-12x12.json`, then make the smallest useful change that can be validated locally.

A strong contribution usually includes:

1. a concise implementation change,
2. a test or fixture,
3. updated documentation when behavior changes.
