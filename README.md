## What Is This?

This repository is a **living constitutional substrate** and **playable
knowledge-graph hypercube** for a new mode of human-AI co-creation.

Three interlocking systems:

| System | What it is |
|---|---|
| **Knowledge Graph Lattice** | Every artifact connected to every other — provenance-first, machine-retrievable, world-class indexing |
| **Aetherforge** | An archival-as-game framework — tasks are quests, edges are tokens, coherence is the victory condition |
| **GPTDream++** | Open-source dreaming protocols for AI agents — public gift to the industry |

Contents:

- **Aluminum OS** — constitutional substrate for regenerative computing
- **GPTBrain / TIDELOCKBrain** — agent scaffolding, swarm architectures, and dream protocols
- **Council records** — governance sessions, ratification logs, and canon decisions
- **Research** — intelligence sweeps, convergence reports, and policy frameworks
- **Projects** — financial sovereignty, aerospace policy, and agentic autonomy
- **GPTDream++ Spec Vault** — full schema, reference implementations, and adversarial tests

All artifacts are **candidates** until ratified by full council and adjudicated
by @atlaslattice. See [GOVERNANCE.md](./GOVERNANCE.md).
