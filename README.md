## What Is This?

This repository is a **living constitutional substrate** for a new mode of
human-AI co-creation. It contains:

- **Aluminum OS** — a constitutional substrate for regenerative computing
- **GPTBrain** — agent scaffolding, swarm architectures, and dream protocols
- **Council records** — governance sessions, ratification logs, and canon decisions
- **Research** — intelligence sweeps, convergence reports, and policy frameworks
- **Projects** — financial sovereignty, aerospace policy, and agentic autonomy

All artifacts are **candidates** until ratified by full council and adjudicated
by @atlaslattice. See [GOVERNANCE.md](./GOVERNANCE.md) for the ratification process.
