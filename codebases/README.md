# Codebases

> *Status: CANDIDATE — not canon until ratified by @atlaslattice*

## What This Folder Is

The `codebases/` domain is the practical build surface for the archive: a collection of source repositories, experiments, adapters, notebooks, and implementation fragments that express Atlas Lattice ideas in executable form. It spans multiple projects and languages rather than representing a single coherent application.

This folder is best read as an overview shelf for working code. It complements the doctrine-heavy docs and vault materials by showing where architectural ideas, automation utilities, and prototype systems have been translated into files that engineers can inspect directly.
