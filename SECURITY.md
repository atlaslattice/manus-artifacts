# Security Policy

## Supported Versions

This repository primarily contains research documents, governance artifacts, and system specifications. There is no versioned software release cycle at this time.

## Reporting a Vulnerability

If you discover a security vulnerability in any code or infrastructure contained in this repository (e.g., CI workflows, Python scripts, automation tooling), please **do not open a public GitHub issue**.

Instead, report it privately:

1. **GitHub Private Vulnerability Reporting** — Use the [Security tab](../../security/advisories/new) to submit a private advisory.
2. **Email** — Send details to `security@atlaslattice.org`.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested remediation

We will acknowledge your report within **72 hours** and aim to resolve confirmed vulnerabilities within **14 days**.

## Sensitive Content

If you discover content in this repository that appears to contain private keys, credentials, personal health data, or other sensitive personal information that should not be public, please report it through the same channels above.

## Responsible Disclosure

We ask that you:
- Give us reasonable time to investigate and remediate before public disclosure
- Avoid accessing, modifying, or deleting data beyond what is needed to demonstrate the vulnerability
- Act in good faith to avoid privacy violations, data destruction, or service disruption
