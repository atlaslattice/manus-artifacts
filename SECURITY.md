# Security Policy

## Scope

This repository contains governance, research, and operational artifacts.  
If you discover a potential vulnerability, data exposure risk, or integrity risk, report it privately.

## Reporting

- Open a private security advisory or contact repository maintainers directly.
- Do **not** publish exploit details in public issues before remediation.

Include:

- Affected path(s)
- Reproduction steps
- Impact assessment
- Suggested mitigation (if available)

## Response Targets

- Initial acknowledgement: within 72 hours
- Triage decision: within 7 days
- Remediation plan: as soon as impact and scope are confirmed

## Disclosure

Please use coordinated disclosure. Public disclosure should wait until maintainers confirm remediation or mitigation guidance.
