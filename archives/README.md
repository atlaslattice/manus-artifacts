# Archives

> *Status: CANDIDATE — not canon until ratified by @atlaslattice*

## What This Folder Is

The `archives/` domain preserves continuity artifacts that help sessions survive interruption, resume accurately, and retain state across campaign waves. In practice, it currently centers on the Janus checkpoint stream: lightweight resurrection logs that capture what just happened, what matters next, and what should not be forgotten.

This folder is an operational memory surface rather than a theory vault. It is useful when reconstructing recent work, tracing decision context, or rehydrating an agent that needs a current checkpoint before touching the broader archive.
