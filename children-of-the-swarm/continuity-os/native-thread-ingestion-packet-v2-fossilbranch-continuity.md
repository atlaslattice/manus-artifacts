## 13. Repo Protocol Addendum

```text
repo intent ≠ repo state
drafted artifact ≠ committed artifact
commit attempt ≠ landed file
landed file ≠ ratified doctrine
```

Required repo write loop:

```text
1. Draft artifact.
2. Write to repository.
3. Fetch target path or commit state.
4. Confirm branch, path, and content.
5. Emit receipt with repository, branch, path, commit SHA if available, file SHA if available, status, and next action.
```
