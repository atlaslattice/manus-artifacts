# OpenAI Operability Layer

Independent OpenAI-adjacent integration layer for Atlas Lattice / GPTDream / Codex / eval / agent synthesis.

This directory is an atlas, boundary, and execution-readiness surface. It is not a mega-repo and does not imply OpenAI endorsement, partnership, deployment, ratification, ownership, or authority.

## Purpose

- Track useful OpenAI and OpenAI-adjacent upstream repositories.
- Preserve fork/reference receipts, license notes, sync policies, and integration roles.
- Keep Codex patch execution bounded by explicit human review.
- Define custom eval targets for provenance, authority leakage, canon drift, and safe patching.
- Provide a clean starting point for developers, Codex, Copilot, ChatGPT, and future agents.

Fork primitives. Reference libraries. Receipt licenses. Build evals. Keep Codex bounded. Keep human-root review above execution.
