# Governance Fire Drills
Status: Candidate
Date: 2026-05-26

This protocol defines recurring tabletop exercises for governance resilience.
Fire drills make sure the archive can respond to failures before the failures become public trust crises.

## Drill format

- scenario briefing
- role assignment
- timed response walkthrough
- decision and escalation review
- post-drill notes and remediation owners

## Recommended scenarios

| Scenario | Focus |
| --- | --- |
| Candidate mistaken for canon | status discipline and public correction |
| Broken lineage in flagship series | archival continuity |
| Missing steward for critical domain | succession safety |
| Website publication of under-reviewed artifact | trust and publication controls |

## Frequency

Run at least one governance fire drill per quarter and at least one canon-integrity drill per year.

## Outputs

- dated drill summary
- gaps discovered
- action owners
- target date for re-test
