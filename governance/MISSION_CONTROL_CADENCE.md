# Mission Control Cadence
Status: Candidate
Date: 2026-05-26

This document defines the operating cadence for archive stewardship.
It turns the Aetherforge improvement gameboard into a recurring discipline instead of a one-time sprint.

## Weekly standup template

- wins from the last week
- blocking risks
- stale artifact triage
- stewardship gaps
- next highest-leverage actions

## Monthly review template

- dashboard refresh
- scorecard review by domain
- candidate promotion pipeline review
- risk register updates
- roadmap checkpoint

## Quarterly all-council template

- state of archive summary
- canon promotion window review
- governance fire drill review
- external review needs
- public communication priorities

## Annual audit template

- full canon audit
- retention and succession review
- trust charter health check
- lessons learned and next-year priorities

## Principle

Mission control exists to keep all five rings of Metatron's Cube moving in rhythm: identity, navigation, quality, public productization, and governance continuity.
