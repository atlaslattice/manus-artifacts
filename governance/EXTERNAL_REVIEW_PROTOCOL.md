# External Review Protocol
Status: Candidate
Date: 2026-05-26

This protocol defines how high-stakes artifacts should be reviewed by external parties.
External review is a trust amplifier only when scope, confidentiality, and integration rules are explicit.

## When to use external review

Use external review for:

- high-impact project doctrine
- public trust-sensitive governance changes
- claims requiring specialist scrutiny
- materials with unusual reputational, legal, or safety implications

## Scope definition

Every external review request should specify:

- artifact paths under review
- review questions
- desired review depth
- whether the review is advisory or gating

## Confidentiality and NDA posture

Public-first review is preferred when possible.
If confidential material must be shared, use the minimum necessary scope and formalize any NDA requirements outside the repository record while preserving a public note that external review occurred.

## Review package

Provide reviewers with:

- artifact summary
- lifecycle status
- known risks and open questions
- provenance packet if relevant
- response deadline

## Integration path

After review:

- summarize findings
- classify feedback as blocking, advisory, or informational
- assign owners for changes
- link the review outcome from the relevant governance record when appropriate

## Principle

External review should improve judgment, not obscure responsibility.
Final authority still follows repository governance and adjudication rules.
