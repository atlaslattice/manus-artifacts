# Support

Thanks for using and contributing to **manus-artifacts**.

## Scope

This repository is maintained as a public, open-source archive for Atlas Lattice Foundation artifacts and supporting documentation.

## How to get help

- **Questions / usage help:** open a GitHub Discussion or Issue in this repository.
- **Bug reports:** use the Bug Report issue template.
- **Feature requests / archive improvements:** use the Feature Request issue template.
- **Security concerns:** follow the process in [SECURITY.md](./SECURITY.md).

## What to include in support requests

Please include:

- The file(s) or section(s) involved
- The observed problem
- Expected behavior or desired outcome
- Links to relevant artifacts/PRs/issues

## Maintenance expectations

- Best-effort maintenance by project stewards and community contributors
- No guaranteed response-time SLA
- High-priority handling for security and data-integrity issues

## Canon governance reminder

Per repository governance, artifacts are treated as candidates unless ratified and adjudicated through the documented canon process.
